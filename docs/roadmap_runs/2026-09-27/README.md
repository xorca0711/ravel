## What changed scientifically

P1 replaces a material uncertainty with source evidence: split culture wells are not independent biological preparations. Recombinant EGF also changes interpretation of the AREG null. P4 quantifies how unresolved identity limits source claims. Neither result demonstrates a new repair mechanism. Previously saved estimates, claim grades and frozen protocols remain unchanged.

P2's failed gates are not a failed biological replication. The bounded primary-plus-fallback search is complete, without claiming that all public cohorts are ineligible. P3's nomination and P5's design are not discovery results.
