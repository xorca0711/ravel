# Rationale review: what the current narrowing supports

4 November 2026. All 33 owner narratives have completed scientific/editorial
cross-review under the [approved restructuring plan](README.md).
The [coordinator review](COORDINATOR_REVIEW.md) records corrections and evidence. This table
is an interpretation guide, not a new question register, scientific acceptance
scale, target ranking or instruction to retire an RQ. Owning reports retain the
actual results and their source/unit definitions.

The review asks whether a narrower claim follows from the measured comparison.
A result can support a limited description or expose a failed explanation without
selecting a new mechanism. Outcome-exposed annotation, reused sources, technical
sensitivity and missing comparisons restrict claims; they do not by themselves
prove that a pattern is random noise. A better-defined proposal is useful, but is
kept distinct from an empirically selected target.

## Consequence for the portfolio

Keep the supported observation and its adverse/sensitive results together. Correct
an unsupported explanatory step instead of erasing the analysis or substituting
a more attractive gene. Each current owner page specifies what the result changed
and which next comparison could discriminate the remaining explanation. Missing
function does not invalidate a useful descriptive or predictive result; a completed
computation does not establish function or mechanism either.

Read the local literature context for published premises and exact access limits,
and the linked current report for repository evidence. Shared samples, same-source
reanalyses and repeated technical settings do not become independent validation.
No new biological calculation or broad literature search was performed for this
summary. Figures remain either registered proposals or provenance-bound measured
results, with their meaning stated in the owning page.
