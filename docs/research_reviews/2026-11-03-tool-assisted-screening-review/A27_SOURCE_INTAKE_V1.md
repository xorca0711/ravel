3 November 2026. Metadata recovery only. The biological question is whether the aging repertoire observation reflects redistribution of T-cell states, within-state clone concentration, or both. The endpoint needs clone membership/abundance linked to RNA-defined state in the same compartment and biological unit. Cells, receptor libraries, hashtags and pooled mice are not interchangeable independent animals. ## Decision and remaining work

A27's next candidate decision requires jointly observed repertoire and state. If a genuine within-state concentration contrast remains after state redistribution is described, both processes may contribute; if the pooled pattern is explained by redistribution and within-state contrasts are sufficiently measured, the concentration interpretation weakens in that source. Clone size alone does not establish antigen specificity, function or causality. No claim about these outcomes is made from metadata.

The most concrete new lead is GSE347791, but it remains **source-qualified in part, not execution-qualified**. Exact next step: locate an actual processed receptor table from that source's documented public distribution and verify barcode/hashtag/mouse joins for all samples, chain/productivity definition, missingness and state-label independence. Then define the mouse-level age/sex comparison and representation denominator for coordinator review. For GSE145562, use the pool as the unit and explicitly limit inference if pursuing that alternative. Do not invent individual mice or reuse another study's clones. No numerical freeze, raw-read reconstruction, new package installation, author contact or controlled-access request was made.
