# A31: depth-conditioned fixed-partner specification v1

No new partner endpoint has been computed. This draft awaits coordinator review before code/contract freeze and execution.

Purpose: distinguish residual same-cell GRIA1/partner detection from marginal abundance and measured depth, then compare this context between original alveolar and adventitial fibroblast labels. Unit: source donor within assay, with linked P1/P3 and A26 identities retained; cells, protocols and regions are nested observations. Endpoint: observed minus marginal-expected joint detection in shared depth bins. This is descriptive conditional association, not receptor assembly, protein, localization, GRIA1 dependence or causal response.

Reuse the immutable cell/count primitives from A31_partner_context_v1_20261103, without rebuilding source matrices. Fix GRIA1 against all eight partners: GRIA2, GRIA3, GRIA4, CNIH2, CNIH3, CACNG2, CACNG3, CACNG8. Preserve original source/assay/donor/region/protocol and reads/UMIs/source_counts semantics. Restrict paired inference to the same distal Travaglini and Lower Left Lobe/Upper left lobe Madissoon regions. All 29 attempted original matched strata remain; non-fibroblast neural labels remain prior anatomical context outside this new paired estimand, not a new exclusion justified by RNA results.

Depth design, chosen without target outcomes: bin full source library L by floor(log2(L)/w), with primary w=0.5 (within-bin maximum/minimum library ratio below 2^0.5, approximately 1.414) and prespecified coarser sensitivity w=1.0. No cross-assay/protocol bins. A bin is shared only if each fibroblast label has at least five cells. Preserve the original at-least-20-cell label floor and require at least 20 retained common-bin cells per label. These are measurement eligibility thresholds, not a power or effect-size justification. Record all bin/label counts, retained fractions and excluded depth ranges; no target-positive minimum, bin merging or post-result retuning. Depth-only feasibility gives 14/29 eligible primary strata and 15/29 coarse strata, compared with 15/29 original supported pairs. The extra coarse result cannot rescue a failed primary result.

For each shared bin and label, n is all cells, a is GRIA1 detected, b is partner detected, and j is joint detection. Observed=j/n; marginal expectation=(a/n)*(b/n); residual=observed-expectation. This expectation corresponds to independent within-bin pairing at fixed margins, not a fitted causal null. Residual magnitude depends on both marginal prevalences: a zero or near-zero residual when one target is absent is not evidence of biological independence or absent machinery. Use common bin weights min(n_alveolar,n_adventitial), normalized to sum to one, for BOTH labels. Save all raw counts, the two marginals, expected joint, observed joint, residual and weights. Standardized label difference is alveolar minus adventitial residual under this same observed-overlap depth distribution. Report standardized observed/expected components too; zeros and negative residuals are retained. Binning only partially conditions on depth and changes the target population to common support.

Aggregate eligible matched strata equally within source donor/assay, preserving region/protocol counts and roster. Show every donor/assay and every partner rather than ranks or a chosen positive subset. Within an assay with at least two donors, report leave-one-donor-out means as descriptive influence; the same person's repeated assay records remain linked and no pooled cross-assay independence claim is allowed. No cell-level p-values, permutation significance, new expression score or population confidence intervals. All unsupported donor/stratum/partner dispositions remain explicit.

Validation: verify source hash, unique source cell IDs, nonnegative integer libraries/targets, all 29 original strata, metadata support parity, joint-set bounds, sum-to-one common weights, scalar reconstruction of residuals and label/donor differences. Synthetic fixed-margin enumeration checks the expected joint formula. Reconstruct all-depth nine-gene counts against the prior immutable primitives before interpreting the new endpoint. Output all eight partner observed/expected and donor-context plots plus complete support tables, with clear assay labels.

Limits: a residual can reflect unmeasured state, composition, ambient RNA, within-bin depth or annotation. Positive association nominates context only; disappearance is compatible with measurement/composition. Any nonoverlapping-cohort intake follows result review and must establish distinct source donors and compatible identity/assay; an atlas repackaging is not replication. No source search or functional claim is automatically triggered by an arbitrary sign threshold.

Runtime: only the existing 14,142-cell compact source is needed. Python/pandas/numpy and existing plotting libraries suffice; no installation or large matrix copy is required. Maximum data work is two depth designs by 29 strata by eight partners; no Monte Carlo stage.
