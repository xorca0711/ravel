## Repository observation and decision

The existing [A21 result](../../../RQ_Specified/A21_fzd4_capillary_function/RESULTS.md)
and [extension](../../../RQ_Specified/A21_fzd4_capillary_function/extensions/extension_v1/RESULTS.md)
already screen all ten Fzd receptors, Foxf1/Lrp6 context and the Bian source
workbooks. Bian Fig. 7 supports a tumor-vessel restoration precedent. Its separate
Fig. 3F Foxf1-loss perfusion result is not an Fzd4-rescue perfusion measurement.

**Published premises → repository observation → remaining question:** endothelial
states have different measured properties; the repository finds Fzd4-associated
stable capillary RNA context and a tumor-vessel precedent; it remains unresolved
whether Fzd4 changes survival/maintenance, regenerative entry or both in adult
repair. Recent endothelial papers sharpen these alternatives, without completing
the missing receptor-specific comparison.

**Plan implication:** reuse the completed receptor screen. Do not add another
RNA score and label it vascular function. A new descriptive analysis is justified
only if it tests a distinct, specified RNA-state contrast; a functional claim
requires a receptor-attributable comparison with the relevant measured outcome.
The source leads above do not automatically qualify for that claim. Positive,
null or mixed RNA associations would remain candidate-context evidence.

**Hold and reopening condition:** no inspected source currently joins the adult
normal-repair Fzd4 comparison to the required maintenance/survival or traced
output measurement. A dataset with a narrower directly measured endpoint can
support that narrower effect question; it need not supply every mechanism at
once. No absence-of-search-hit novelty claim is made.
