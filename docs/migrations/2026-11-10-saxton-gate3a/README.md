## Validation and review

The research-gate extension verifies source ancestry and Git blob hashes,
destination hashes, safe unambiguous paths, retired source files, and retention
of accepted mapping records. Only already registered assets can receive the
exact-move allowance. Frozen contracts/receipts and the historical baseline
remain immutable. The runner blocks migrated archival contracts/code/inputs:
future execution requires a new version using current paths.

Synthetic regression tests cover preserved receipt validation, tampering,
missing/reappearing files, unsafe and ambiguous mappings, forged source hashes,
invalid revisions, map removal, and replay refusal. The PR must receive explicit
owner review of this validator/governance change before merge. Agent-authored
checks are not independent approval. External branch protection and account
settings are not changed by this PR.
