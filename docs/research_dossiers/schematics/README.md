The [28-question guide](../literature_context_2026-10-03/README.md) embeds the
schematics in the actual RQ READMEs or the seven existing dossier contexts.
Twenty-one dedicated RQ folders contain their own `schematics/` SVG. This folder
holds the seven companions whose execution remains in existing article/shared
workspaces. These are editable original vectors, not copied publication figures.

companions grounded in the latter revision. The older private atlas remains

Each SVG is its editable source; no biological input table or analysis run
produced these qualitative drawings. Original drawing primitives were rendered
to SVG and PDF for inspection. The four added pages received text-bound checks
and rendered-page inspection; the reused 24 retain their prior full-atlas check.
The registry's `question_guides` records the exact SVG content hash, source
revision and full working-hypothesis hash. No illustrative hash is a biological
run receipt. Context notes and repository reports supply the scientific limits.

Purple dashed arrows denote the labelled candidate comparison; orange denotes
a rival. Cell numbers, shapes, sizes and colours are qualitative. A gray question
mark is a real missing specification. The readout cards explain the information
earned from a measurement, not an operational bench protocol.

Correct a drawing in a new versioned SVG and retain the old one. Update its
registry entry and caption together, then run the research gate. A changed
dossier hypothesis requires renewed figure/context review. Do not regenerate
historical measured figures to update these explanatory companions.
