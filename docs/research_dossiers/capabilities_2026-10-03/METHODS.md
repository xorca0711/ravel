# Published model and assay evidence

Source IDs identify the local files in [CORPUS.md](CORPUS.md); page numbers are
one-based PDF pages, including covers. Published conditions below constrain
interpretation, not a new laboratory recipe. Source methods own implementation.
No current colony, reagent transfer, patient tissue supply or host access has
been confirmed. Genetically modified tracing mice, spontaneous cancer models,
transplant tumors, primary organoids and reporter cell lines are distinct systems.

## Supporting resources and model-choice limits

P07 (Tabula Muris Senis) is an age/sex/tissue reference, not a matched longitudinal
intervention; its C57BL/6JN animals and processing history matter. P14/P30 (human
lung atlas/HLCA) support identities and sampling context, not lineage, migration
or functional competence. Shared atlas contributors are not independent external
replication. P24 is a review; P27/P31/P32 are computational methods. None proves
that a wet assay is available. P06 is a tumor/Wnt comparison, not a normal repair
model. Main-paper and supplementary PDFs from one study are one evidence source.

For any future bench design, record the exact genotype/background/sex/age,
lineage driver and labeling specificity; specimen origin and pathology; primary
versus transformed status; donor/pool/preparation, passage and culture composition;
assay platform and actual measured endpoint. Match these to the intended claim.
The requirement applies equally to a convenient existing platform and a new one.

The model with the fewest components is useful only if it retains the causal
comparison. A receptor reporter can establish assay response; a primary organoid
can test a defined epithelial–stromal contrast; tissue slices retain architecture
but have donor/access and viability limits; an in vivo lineage model can test
integrated repair but needs an established colony and qualified endpoints.
None is an automatic substitute for the others.
