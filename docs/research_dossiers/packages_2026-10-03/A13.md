# A13 — nominate an output before testing niche causality

Proposed evidence-decision package. [Dossier](../A13.md) · [Common terms](README.md).

**Published:** [Kaiser 2023](https://doi.org/10.1084/jem.20221462),
[Hoffman 2025, coculture comparisons](https://doi.org/10.1038/s41467-025-63735-1)
and [Cardoso 2026, niche experiments](https://doi.org/10.1038/s41586-026-10399-6)
already establish important fibroblast support/circuit precedents.
**Repository:** [current workspace](../../../RQ_Specified/A13_fibroblast_beyond_macrophage_il1b/README.md)
retains the unsuccessful twelve-triad proxy model;
[coverage result](../../../RQ_Specified/A13_fibroblast_beyond_macrophage_il1b/reports/COVERAGE_RESULTS.md)
does not qualify an external triad. Neither result nominates a mediator.

**Hypothesis/decision:** Fibroblast output may alter epithelial recovery beyond the effect of macrophage IL-1-beta input. The existing TGF-beta-hallmark/HPCS-proxy pilot found no aggregate held-out gain and nominates no mediator. The biological idea remains incomplete until a particular fibroblast product, epithelial response and source-directed contrast are supported; output nomination is preparatory work, not the hypothesis itself.

**Current novelty boundary:** Reciprocal epithelial-fibroblast effects and inflammatory fibroblast outputs already have functional precedents. A generic additional fibroblast effect or another score fit would not establish novelty. [Source comparison](../NOVELTY_SPECIFICITY_APPLICATION_2026-10-03.md#a13). Existing design rows are conditional; the specificity holds above must be resolved before treating them as an experiment specification.

| Design element | Conditional specification |
|---|---|
| Immediate population/unit | Published primary fibroblast–epithelial systems with explicit donor/preparation units and a defined inflammatory context. The first decision is measurement nomination, not another score fit. |
| Contrast/timing | Audit source-output measurement preceding epithelial consequence, with source number/viability and input history recorded. Keep fibroblast-to-epithelium direction explicit. |
| Primary outcome/denominator | A nomination record identifying an actually measured output, a compatible independently measured epithelial recovery endpoint, source/recipient units and timing. No molecule is selected merely to fill this field. |
| Required controls for the later test | Input-matched source-present/source-absent contrasts, source-amount and source-viability accounting, recipient-only control and validated output/recipient response references. A source-directed contrast needs demonstrated specificity. |
| Competing results/action | Output-associated recovery at comparable source amount/input warrants a bounded prospective test. Effects tracking support-cell depletion leave activity-specific attribution unresolved. A valid negative output test narrows only that output/context. |
| Stop/limit | No qualified output/endpoint pair: keep the causal branch on hold. A new hallmark score cannot rescue the negative proxy model or establish feedback. |

**Novelty:** the new discriminator must add to published reciprocal niches;
generic bidirectionality is already known. M is a possible recovery endpoint
only in a lineage-compatible model; growth alone is insufficient.
**Precision/access:** output assay, meaningful recovery effect, variance and
sample size are unknown. Actual coculture/lineage access is unconfirmed.
Once nominated, freeze one primary output/response contrast and control any
secondary panel. An unresolved nomination is a precise next decision, not an
experiment-ready mechanism.
