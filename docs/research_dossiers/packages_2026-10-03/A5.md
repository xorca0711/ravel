# A5 — replicate the frozen developmental component

Proposed evidence-decision package. [Dossier](../A5.md) · [Common terms](README.md).

**Published:** [Guo 2019](https://doi.org/10.1038/s41467-018-07770-1)
defines developmental states; [Strunz 2020](https://doi.org/10.1038/s41467-020-17358-3)
defines the repair context.
**Repository:** [revised A5 result](../../../RQ_Specified/A5_A11_shared_component_contract/reports/REVISED_TEST_RESULTS.md)
retains positive recruitment across 24 primary mice after the specified
exclusions. [External metadata](../followup_2026-10-03/METADATA.md) joins
libraries but not author states/mice; 56 libraries versus 55 reported mice is unresolved.

**Hypothesis/decision:** the exact independently sourced developmental component
is recruited in an independently qualified adult repair cohort beyond the fixed
identity/stress comparators. Rival: annotation, composition or generic plasticity.

| Design element | Conditional specification |
|---|---|
| Population/unit | Author-labelled repair transitional and comparator epithelium within biological mouse at supported times. Retain the existing frozen component and eligibility rules. Library and mouse are not interchangeable. |
| Contrast/timing | Replicate the prespecified within-mouse RNA contrast at comparable repair stages. Audit cohort/source reuse before calling it external replication. |
| Primary outcome/denominator | Paired detection-probability difference on the existing score scale and UMI budget, using its frozen gene and library definitions. Existing exclusion modules are declared secondary, with the original family carried forward. |
| Controls/validity | Barcode-to-library-to-mouse/state joins; full measured-gene denominator; reference state independent of tested genes; coverage, depth and excluded identity/stress panels. No relabeling to increase agreement. |
| Competing results/action | Reproducible contrast supports partial transcriptional reuse and a separately nominated functional study. An adequately precise failure narrows transfer; ambiguous labels hold the test. Neither outcome establishes developmental ancestry. |
| Functional sequence/stop | Only after replication/measurement qualification nominate a repair process and linked lineage/function endpoint. No single gene target is inferred from this module. Preserve the original positive result even if replication fails. |

**Novelty:** reactivation of developmental programmes is established broadly.
The increment is reproducibility of this fixed component and, later, its
independent functional information; a novel module name is insufficient.
**Precision/access:** effect margin and independent-mouse variance for the
external cohort are unknown. Needed artifact: the named author-object export
with barcode, library, mouse, original state and pool/split memberships.
No host access is needed to qualify a real export; none has arrived. A future
functional platform and assay remain unconfirmed.
