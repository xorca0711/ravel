# A3 — prior history versus age, origin and present context

Proposed evidence-decision package. [Dossier](../A3.md) · [Common terms](README.md).

**Published:** [Aegerter 2020, origin/history comparisons](https://doi.org/10.1038/s41590-019-0568-x)
provides a direct precedent; [Niethamer 2025](https://doi.org/10.1016/j.stem.2024.12.002)
provides the repository's host-cell context.
**Repository:** [current article evidence](../../../Research%20Article/gate1_01_niethamer_2025/README.md)
retains age/processing confounding, negative CAMERA findings and the ineligible
ornithine set. Compass was not run.

**Hypothesis/decision:** Prior lung injury may leave a persistent macrophage programme within comparable macrophage origins and states after the current environment has resolved. The additional question concerns history beyond age, origin and continuing tissue stimulation. A programme and independent functional consequence still need nomination; late sampling alone cannot demonstrate biological memory.

**Current novelty boundary:** Macrophage history, origin and age effects are already reported. A narrower wording or adjusted late-state score alone does not establish a new functional contribution. [Source comparison](../NOVELTY_SPECIFICITY_APPLICATION_2026-10-03.md#a3). Existing design rows are conditional; the specificity holds above must be resolved before treating them as an experiment specification.

| Design element | Conditional specification |
|---|---|
| Population/unit | Source-defined macrophage origins/states in age-compatible animals or independently documented human donors. Animal/donor, not macrophage, is the unit; no cross-species pooling. |
| Contrast/timing | Existing-data comparison of prior history at a common later interval, stratified by documented age, processing and present environment. Origin requires independent evidence, not the same RNA programme. |
| Primary outcome/denominator | Between-unit contrast in a fixed programme within a shared state, with all measured genes supplying the library denominator and eligible donor-state units displayed. This is an association endpoint. |
| Controls/validity | No-history age reference, processing-balanced comparison, state labels independent of the test panel, composition/viability and origin coverage. A model cannot repair complete age-by-study confounding. |
| Competing results/action | Robust history association warrants separate functional nomination. Loss under supported age/origin/context restriction favors the rival. A wide interval leaves the question open. |
| Functional sequence/stop | First resolve metadata and a meaningful host consequence; no effector is selected by the failed gene-set analysis. Any metabolic branch must distinguish RNA prediction, metabolite abundance and measured flux. Hold intrinsic-memory claims without independent history-versus-environment evidence. |

**Novelty:** persistent macrophage changes are known; separating these exact
rivals is the potential increment. Pathogen-related papers are used only for
host evidence, without new exposure procedures.
**Precision/access:** a programme-effect scale and functional endpoint must be
justified before effect margins or sample size. Independent aged/history-matched
material is unconfirmed. One bounded programme is primary; another pathway
search would be an exposed exploratory amendment, not a rescue.
