# A4 — response sequence within a starting AT2 lineage

**Proposed 3 October qualification:** the [current review](../continuation_2026-10-03/PACKAGE_REVIEW.md#material-refinements) clarifies the t0 lineage denominator, missing follow-up and survivor-conditioned secondary fraction. Apply that refinement when specifying a new prospective comparison; owner scientific review remains pending.

Proposed conditional package. [Dossier](../A4.md) · [Common terms](README.md).

**Published:** [Frank 2016](https://pubmed.ncbi.nlm.nih.gov/27880906/),
[Nabhan 2018, lineage figures](https://doi.org/10.1126/science.aam6603) and
[Choi 2020](https://doi.org/10.1016/j.stem.2020.06.020) constrain novelty:
dynamic Wnt responsiveness and inflammatory transition are established.
**Repository:** [Nb1 evidence](../../../Research%20Article/gate1_03_nabhan_2018/README.md)
does not supply the required acute sequence; the
[linkage audit](../followup_2026-10-03/OUTCOMES.md) keeps lineage history separate
from current reporter activity.

**Hypothesis/decision:** Adult AT2 starting lineages with documented Wnt-responsive history can later acquire an IL-1-beta-responsive transitional epithelial state, rather than the apparent sequence arising only from expansion or survival of different pre-existing subsets. Wnt history, current Wnt activity and current IL-1 response must be measured separately. This restores the existing sequence question; it does not adopt the proposed Fzd5-dependent gate on transition entry.

**Current novelty boundary:** Dynamic Wnt responsiveness and inflammatory AT2 transitions are established. The possible increment is the linked adult Wnt-history-to-IL-1 sequence versus within-population selection. The Fzd5 entry-gating proposal remains unsupported as current scope. [Source comparison](../NOVELTY_SPECIFICITY_APPLICATION_2026-10-03.md#a4). Existing design rows are conditional; the specificity holds above must be resolved before treating them as an experiment specification.

| Design element | Conditional specification |
|---|---|
| Population/unit | Prospectively identified AT2 starting lineages with independent Wnt-history and current-activity measurements. Clones/descendants nest in animals or independent donor preparations. |
| Contrast/timing | Document history/current state at t0, then compare defined input histories and early response at t1, with descendant accounting at t2. Include comparable initially history-negative populations. |
| Primary outcome/denominator | Prespecify the eligible t0 lineage set. Report response, measured loss and unresolved follow-up separately over that set, with missing-response bounds; a survivor-conditioned response fraction is secondary. Also count responsive descendants per t0 labelled AT2 input. Population lineage labeling alone may not distinguish selection within that lineage. |
| Controls/validity | Label specificity/efficiency, reporter persistence, label-only/input-free controls, positive response reference, survival and division accounting. Validate response using engagement plus an independent downstream readout, not ligand RNA. |
| Competing results/action | Response change resolved within tracked starting clones supports flexibility. Stable subset responses plus selective expansion favor selection. Mixed patterns support both processes rather than a binary conclusion. |
| Stop/limit | Hold switching inference when only destructive unlinked snapshots or broad lineage fractions exist. No pseudotime-to-lineage substitution. Generic AT2 plasticity is not the contribution. |

**Precision/access:** define a meaningful difference in lineage response and
between-animal/clone nesting variance before sample sizing. Current lineage
models and response measurements have no confirmed access. Primary response
sequence is one comparison; later maturation is secondary unless separately
specified. The next enabling export joins t0 history, current activity,
clone/animal, input history, t1 response and t2 viable descendants.
