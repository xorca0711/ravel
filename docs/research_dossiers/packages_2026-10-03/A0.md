# A0 — qualify the cross-tissue construct before reopening

Proposed evidence-decision package. [Dossier](../A0.md) · [Common terms](README.md).

**Published:** [Strunz 2020](https://doi.org/10.1038/s41467-020-17358-3),
[Sountoulidis 2023](https://doi.org/10.1038/s41556-022-01064-x) and
[Haber 2017](https://doi.org/10.1038/nature24489) describe different tissue/state
comparisons; trajectory position is not common lineage or function.
**Repository:** [current pilot](../../../RQ_Specified/A0_conserved_epithelial_transition_program/reports/PILOT_V1_RESULTS.md)
failed its fixed lung-to-intestine transfer. The source is an injured alveolar
axis plus a human developmental airway axis; neither makes intestinal late
progenitors an equivalent transient state.

**Decision/hypothesis:** determine whether independently defined biological
correspondence can distinguish restricted expression of the frozen component
from a mismatched transfer construct. Strongest rival: the proposed transitions
do not share the tested intermediate-versus-both-endpoints meaning. This is not
a revised positive conservation hypothesis.

| Design element | Conditional specification |
|---|---|
| Population, unit and starting state | Source-defined lung and intestinal populations with original donor/mouse identities; cells nest in units. No new target population is selected from the failed score. |
| Observation and timing | Compare independent lineage, anatomy and time evidence for source/target state correspondence before examining any new module effect. Preserve each study's time scale. |
| Primary outcome/denominator | An auditable mapping decision: which proposed starting/intermediate/terminal relationships have independent support, which conflict, and which are unknown. Denominator is the complete prespecified set of mappings, not selected agreeing genes. |
| Controls/validity | Check endpoint acquisition, label independence, gene coverage and age/tissue differences. Preserve both endpoint contrasts and the original negative target. Wet positive/vehicle controls are inapplicable to this reading decision. |
| Competing results and action | Supported correspondence plus persistent failure narrows this component's transfer scope. Unsupported correspondence limits what the failed test addresses, but does not justify tuning genes or replacing the endpoint. |
| Stop/interpretation | No independent mapping rationale: keep the original branch stopped. A worthwhile different comparison needs a distinct hypothesis and prospective amendment. No conserved fate mechanism or wet target is nominated. |

**Novelty:** the increment would be construct qualification, not a newly named
shared score; an existing matched functional comparison would remove that gap.
**Precision/access:** no sample-size calculation applies to the mapping audit.
Any subsequent quantitative test needs its own meaningful scale and independent
unit variance. Comparative primary preparations and shared functional endpoints
are unconfirmed. A8 retains lung maturation prediction.
