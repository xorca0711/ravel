# A11 — information in the exact residual beyond shared stress

Proposed evidence-decision package. [Dossier](../A11.md) · [Common terms](README.md).

**Published:** [Marjanovic 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7745838/),
[Chan 2026, Fig. 5c–e](https://doi.org/10.1038/s41586-025-09985-x) and
[Bienkowska 2026](https://doi.org/10.1002/1878-0261.70263) already constrain
generic cancer-plasticity/developmental-reuse claims.
**Repository:** [revised paired-patient result](../../../RQ_Specified/A5_A11_shared_component_contract/reports/REVISED_TEST_RESULTS.md)
supports lesion association while the stronger beyond-shared criterion remains
unresolved; the [exact partition audit](../followup_2026-10-03/NOVELTY.md)
does not identify a novel malignant state.

**Hypothesis/decision:** the fixed disjoint residual adds lesion-context
information beyond the frozen shared component and an independently defined
stress comparator. Rival: residual generic stress, state mixture or labeling.

| Design element | Conditional specification |
|---|---|
| Population/unit | Independent patients with well-defined lesion and non-neoplastic comparators; injury controls at comparable epithelial state, with real pairing only when source IDs support it. |
| Contrast/timing | Contextual association at documented sampling times first. Fix residual, shared and stress definitions before new outcome review; reused Marjanovic data are not an independent validation cohort. |
| Primary outcome/denominator | Held-out patient log-loss improvement for lesion-context classification when the fixed residual is added to the same shared/stress baseline model. Calibration and paired context differences are secondary. Patients, not cells, define holdouts and the biological denominator. |
| Controls/validity | Non-neoplastic injury comparator, state labels independent of modules, gene-overlap audit, coverage/depth and pathology assessment independent of RNA. Preserve the original q=0.0547 stronger-criterion result without threshold tuning. |
| Competing results/action | Reproducible increment supports a bounded context measurement. Comparable recruitment in matched injury or loss under stress comparison favors shared plasticity. Neither supplies a malignant identity or mechanism. |
| Functional sequence/stop | Nominate a lesion-relevant function only after establishing what the residual measures. No gene target or transformation experiment is justified by a set difference. Hold if comparator/source overlap is unresolved. |

**Novelty/precision:** the measurement definition differs from published full
signatures; that alone is not worthwhile biological novelty. Meaningful
increment, independent-patient variance and functional endpoint remain unknown.
One chosen primary estimand and a fixed comparator family precede testing.
**Access:** qualified patient data or suitable lesion/non-lesion models remain
unconfirmed; current source review is not bench readiness.
