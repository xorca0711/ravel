# A2 — delivery, effective availability and fibroblast response

Proposed conditional package. [Dossier](../A2.md) · [Common terms](README.md).

**Published:** [Kaiser 2023, mesenchymal EGFR/AREG experiments](https://doi.org/10.1084/jem.20221462)
and [Cardoso 2026, Figs. 2–4](https://doi.org/10.1038/s41586-026-10399-6)
already establish pertinent epithelial/stromal circuits.
**Repository:** the [current interpretation correction](../../../RQ_Specified/A2_areg_source_delivery/reports/INTERPRETATION_AUDIT_2026-09-27.md)
retains an inconclusive RNA association; EGF-containing medium and shared mixture
splits limit attribution. [MesSTIM identities](../followup_2026-10-03/METADATA.md)
do not resolve biological preparations.

**Hypothesis/decision:** a defined source/presentation context changes recipient
response through altered effective AREG availability. Rival: recipient state,
other EGFR input or source/recipient amount explains the contrast. A residual
effect after equalizing availability is a separate question.

| Design element | Conditional specification |
|---|---|
| Population/unit | A defined fibroblast recipient state and characterized epithelial source in primary coculture. Independent source and recipient donors/preparations, with shared-donor nesting, must be known. |
| Contrast/timing | Compare source contexts at t0 with matched starting viable populations; measure available AREG and recipient engagement at t1, then a defined recipient consequence at t2. A separate input-matched contrast tests residual context effects. |
| Primary outcome/denominator | Total recipient activation response per recorded t0 recipient input. Nominate and validate the concrete response assay before execution; receptor engagement is an intermediate measurement, not the downstream function. Report viable recipient yield separately. |
| Controls/validity | C measurements; medium/other EGFR ligands documented; source-free, recipient-only, reference-ligand and receptor-dependence controls; source/recipient viability and analyte recovery. Technical split wells are nested. |
| Competing results/action | Context changes availability and response: compatible with delivery through supply. Equal response after input equalization does not refute that route. Persistent difference requires recipient-competence/other-input discrimination; it does not establish a special delivery mechanism. |
| Stop/limit | Hold causal inference without biological maps, protein exposure, engagement or a validated recipient consequence. AREG RNA and ITGB6 association do not measure delivery. |

**Novelty/precision:** general AREG–EGFR support is established; the proposed
increment is attribution of a specified context effect. Meaningful recipient
response, variance and primary assay remain unknown; define them before a
single primary contrast and separately controlled secondary mechanism tests.
**Access:** compatible primary sources/recipients and quantitative C assays are
unconfirmed. No ligand engineering or delivery optimization is proposed.
