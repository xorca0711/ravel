# A23 — phosphate handling, transition and viability

Proposed conditional package. [Dossier](../A23.md) · [Common terms](README.md).

**Published:** [Uehara 2023, phosphate/microlith measurements](https://doi.org/10.1038/s41467-023-36810-8)
establishes homeostatic consequences of SLC34A2/Npt2b deficiency.
**Repository:** [external result](../../../RQ_Specified/A23_slc34a2_transition_homeostasis/reports/external_pilot_v2/RESULTS.md)
does not reproduce the coordinated screen marker response; the
[transporter context](../../../RQ_Specified/A23_slc34a2_transition_homeostasis/reports/transporter_context_v1/RESULTS.md)
does not supply transcriptional compensation evidence. A case/control contrast
confounds donor, disease, age and sampling.

**Hypothesis/decision:** altered SLC34A2-dependent phosphate handling precedes a
defined epithelial transition response in the relevant context.
Rival: generalized injury, extracellular mineral conditions, survival or starting
state accounts for marker changes.

| Design element | Conditional specification |
|---|---|
| Population/unit | Identified primary AT2 preparations with documented extracellular mineral context and independent donor/animal parents. The human PAM case is a context observation, not replicated perturbation. |
| Contrast/timing | Compare interpretable transporter/homeostasis contexts with baseline state, early compartment-specific handling, later transition and viability. Record order before choosing a marker endpoint. |
| Primary outcome/denominator | Absolute viable cells meeting an independently validated transition definition per t0 AT2 input, linked to measured phosphate handling. Intracellular/extracellular abundance and transport flux are distinct measurements. |
| Controls/validity | Transport assay positive/negative references, transporter expression/localization, viability/injury reference and mineral-context controls; independent transition identity. An interpretable restoration contrast is a later causal discriminator, not assumed available. |
| Competing results/action | Handling change preceding transition beyond injury/viability supports the proposed route. Injury-only or context-dependent marker change favors rivals. Recovered handling without state recovery separates the endpoints rather than rescuing the hypothesis. |
| Stop/limit | Hold mechanism without handling/timing evidence. Three markers are not fate; lower alternative-transporter RNA does not rule out functional compensation. Preserve the external negative marker result. |

**Novelty/precision:** phosphate homeostasis is established; time- and
compartment-linked transition is the possible increment. Valid transition
definition, meaningful handling/state effects and unit variance remain unknown.
Freeze one primary state endpoint and declare secondary transporter/injury tests.
**Access:** compatible primary material, handling assays and validated state/
viability measurements are unconfirmed. No expression-only substitute is adequate.
