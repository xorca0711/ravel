# A6 — shared macrophage state versus captured abundance

Proposed conditional package. [Dossier](../A6.md) · [Common terms](README.md).

**Published:** [Sikkema 2023, healthy/disease mapping](https://doi.org/10.1038/s41591-023-02327-2)
is a reference, not necessarily an independent cohort. [Yadav 2025, Figs. 3–6](https://doi.org/10.1172/JCI188734)
illustrates why source-cell identity and actual effector measurements matter.
**Repository:** [HLCA workspace](../../../Research%20Article/gate1_04_sikkema_2023_hlca/README.md)
retains three IPF versus one control donor in the proliferating-state comparison.
Owner reservations are not reversed by this package.

**Hypothesis/decision:** a bounded programme changes within a genuinely shared
macrophage state in IPF, beyond altered captured mixture. Rival: state mismatch,
sparse control coverage, processing or abundance accounts for the apparent effect.

| Design element | Conditional specification |
|---|---|
| Population/unit | Verified IPF and control donors with the same independently annotated macrophage state; specimens/regions/cells nested within donor. No forced pairing or zero-filled missing state. |
| Contrast/timing | Cross-sectional disease comparison within each source cohort, at its documented sampling time. Keep abundance and within-state expression estimands separate. |
| Primary outcome/denominator | Donor-state expression contrast for a predeclared programme using full measured-gene libraries; report captured-state fractions separately with their actual captured-cell denominator. Neither is tissue abundance. |
| Controls/validity | State labels excluding tested genes, shared-state coverage, diagnosis, region/assay and age/smoking support; nonoverlap with atlas training/discovery donors. No overfitted adjustment of a one-control comparison. |
| Competing results/action | Reproducible within-state effect warrants nomination of a measured effector consequence. Mixture-only or label-dependent change redirects interpretation to those rivals, not automatic rejection of the RQ. |
| Stop/functional branch | Hold population inference at the current coverage gate. A functional assay must first nominate the macrophage output and recipient consequence; mouse ARG1 source attribution cannot be transferred to human IPF. |

**Novelty:** another disease macrophage label is not the increment. A comparable
state, independent donors and an independent consequence would be.
**Precision/access:** meaningful programme shift, between-donor variance and
functional endpoint remain unknown. One fixed programme is primary, wider
gene screens need a declared family. Primary macrophages or tissue slices
would require donor access and functional calibration; slices do not add donors.
