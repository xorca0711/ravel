# A16 — marker attribution before later-response interpretation

Proposed conditional package. [Dossier](../A16.md) · [Common terms](README.md).

**Published:** [England 2025, Fig. 4](https://doi.org/10.1016/j.stem.2025.01.011)
already examines mutant-state plasticity; a CD177-associated state is not new.
**Repository:** [Stage 1](../../../RQ_Specified/A16_cd177_state_attribution/reports/STAGE1_RESULTS.md)
and its [population erratum](../../../RQ_Specified/A16_cd177_state_attribution/reports/STAGE1_ERRATUM.md)
are read with the current dossier: attenuation, residual imbalance and
inconclusive specificity do not establish intrinsic priming or exclude every
contamination explanation.

**Hypothesis/decision:** epithelial CD177 protein identifies a later response
difference within a comparable starting mutant state. Rival: non-epithelial
source, unequal starting states or an already active response.

| Design element | Conditional specification |
|---|---|
| Population/unit | Independently identified mutant epithelial cells with source/genotype attribution, baseline-state measurement and protein-level CD177. Clones/cultures nest in animals/preparations. |
| Contrast/timing | Compare baseline CD177-positive/negative cells within a qualified state before a later observation. Do not define baseline state with the tested response genes. No CD177 causal manipulation is nominated by this association. |
| Primary outcome/denominator | Initial measurement decision: reproducible epithelial protein localization with donor-resolved specificity. If valid, nominate one later response and denominator before testing; candidate absolute lineage expansion per starting cell differs from state switching or survival. |
| Controls/validity | Antibody/assay specificity and orthogonal localization, epithelial/non-epithelial controls, doublet/ambient assessment, baseline balance, viability and source IDs. Positive RNA alone is insufficient. |
| Competing results/action | Valid attribution plus a later within-state difference supports marker utility. Loss after source/state controls favors the rival. Persistent imbalance leaves attribution open even if an association remains. |
| Stop/limit | Hold later-response fitting without a valid baseline marker and linked endpoint. No intrinsic priming, absence of contamination, causal CD177 role or lineage advantage follows from the current residual. |

**Novelty/precision:** the increment is an independently attributable prospective
marker comparison beyond published plasticity. The primary protein specificity
criterion, meaningful later effect and unit variance are unknown; qualify those
before sample size and multiplicity decisions. **Access:** suitable mutant
primary material, validated antibodies and lineage-compatible follow-up are
unconfirmed. A defined next measurement decision replaces an invented mechanism.
