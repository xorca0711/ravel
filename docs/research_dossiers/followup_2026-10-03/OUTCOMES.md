# Qualification of early-state to later-outcome linkage

**A published lineage or functional endpoint can be real while the proposed predictor-to-outcome comparison remains unidentifiable.** The following decisions concern the exact current RQ. They do not declare whole studies unusable or require a new experiment when an author export might suffice.

This document reconciles existing source audits with the fresh availability and primary-source checks in [SOURCES.md](SOURCES.md). It is a documentation qualification, not a new numerical analysis. Sources are not pooled into a common effect estimate.

## Intake rule for the next article or export

Record source version, biological-unit ID, library/sample ID, starting population, intervention/input, acquisition time, endpoint type, numerator/denominator, viability, assay calibration and parent/pool/split relationships. Report a join as unavailable if any required key is absent. Distinguish prediction, concurrent association and causal attribution before choosing an analysis. This field list is a research-data requirement, not a bench protocol or a sample-size recommendation.
