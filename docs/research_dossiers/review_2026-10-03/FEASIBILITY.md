# Question-by-question feasibility review

All questions remain available. Each next gate is an evidence decision, not an order to run a new experiment. Capabilities are requirements, not claims of current lab access. Primary-source coverage varies and does not establish exhaustive novelty. See the [shared interpretation rules](README.md#shared-interpretation-rules), especially for post-treatment state and cell-number adjustments.

## A0

[Current dossier and repository evidence](../A0.md). **Primary precedents:** [S05](SOURCES.md#s05)

**Possible contribution:** Define the boundary of the failed conserved-programme transfer, not a replacement lung maturation question.

**Current limit:** The fixed 50-gene intermediate-minus-mature intestinal contrast failed in three mice. Source arrows describe populations, not individual ancestry.

**Next decision and capabilities:** Check whether independent biology validates the lung/airway/intestine state correspondence. Retain the stop unless a distinct, independently justified hypothesis warrants an amendment.
