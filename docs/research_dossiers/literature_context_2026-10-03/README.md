# Illustrated research question guide

Explore the **31 registered questions (A0–A30)** by biological topic. Each row
links to the current question page, its explanatory diagram and the literature
context behind it. Topic groups are for navigation, not a priority ranking.

**How to read a question:** the *hypothesis* is the proposed explanation; the
*competing explanation* (called the **rival** in the research records) is the
alternative it must be distinguished from; the *readout* is the measurement
used to distinguish them. A diagram presents the proposed comparison, not proof
of its outcome.

1. **Choose a question** by its topic below. Its title opens the current question page.
2. **Open the diagram** for the visual comparison, then **read the context** for
   published findings, repository observations and interpretation limits.
3. **Check the current evidence and disposition** linked from the question page
   before using an older context note to plan further work.
