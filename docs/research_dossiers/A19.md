# A19: research development dossier

Does epithelial state determine whether ending Fzd stimulation converts AT2 expansion into mature AT1 output while retaining an AT2 reserve?

Status: proposed refinement, 3 October 2026. This is a development aid, not scientific acceptance or an experimental protocol.

## Biological problem

Does starting epithelial state determine mature AT1 output and retained AT2 reserve after Fzd input ends?

## Established knowledge

Maintaining an expandable population and producing mature descendants are different functions. CHIR exposure is not equivalent to receptor-specific Fzd input.

## Repository evidence

The Nb2-derived workspace and later extension narrow the question to withdrawal, mature output and reserve. Pre-withdrawal airway-like state is a candidate competence feature, not established causation.

## Unresolved gap

Starting-state competence, input duration and input identity have not been separated using mature descendant and reserve outcomes.

## Working hypothesis

A defined starting state permits mature output after input withdrawal while retaining a responsive AT2 reserve.

## Competing explanations

Observed differences follow survival, starting population mixture, expansion duration or a generic downstream pathway effect.

## Discriminating outcomes

A starting-state-dependent difference in mature yield and retained functional reserve, after survival accounting, favors competence; growth-only differences favor the alternatives.

## Next investigation

Separate the three estimands in the next contract and qualify lineage, mature endpoint and reserve measurements. Use the current extension boundaries rather than reverting to a generic Wnt question.

## Experimental bridge

Track mature descendants and the retained population's response capacity independently across comparable starting states. Input history and receptor specificity require separate evidence.

## Interpretation boundary

Marker changes or expansion after stimulation do not demonstrate productive mature repair with retained reserve.

## Decision and maturity

A focused experimental concept exists; model, independent-unit variance and endpoint feasibility must be established before confirmation.

Novelty remains provisional: review primary literature around the actual discriminator before calling this a new contribution. Assay validity, meaningful effect size, biological-unit variance and model feasibility must be established before a confirmatory experiment.
