# Conditional package review and proposed refinements

3 October 2026. Scope: agent consistency review of the current package endpoints,
rivals, units and stop conditions against repository evidence and the existing
bounded precedent reviews. This is not independent human scientific acceptance
or a fresh full-text novelty review of every primary paper. All 24 RQs and nine
Nb4 candidates remain available; no priority is selected.

## Material refinements

1. **A4's denominator must precede response and survival.** Its phrase
   “evaluable starting lineages” can conceal informative loss. For a prospective
   comparison, define the eligible t0 lineage set before treatment/response.
   Report response, measured loss and unresolved follow-up separately over that
   set; an observed-response fraction is a lower-bound description when response
   is missing. Show missing-response sensitivity bounds. A fraction restricted
   to evaluable survivors is secondary and cannot by itself distinguish flexibility
   from selection. This is a proposed qualification of the draft, not a new result.
2. **A17's score concerns detected clone sizes until ascertainment is known.**
   The [model specification](A17_MODEL_SPEC.md) separates conditional size
   likelihood from clone counts/extinction, time-regime changes from cell-state
   switching, and numerical qualification from biological identifiability.
3. **Predictive comparisons need a fixed unit-level loss definition.** For
   A1/A8/A10/A11 and the relevant Nb4 packages, specify the per-unit aggregation
   before fitting; numbers of captured cells or images cannot choose the weight
   of a donor/preparation. All feature selection, transformations and tuning
   remain within training units. Use the same folds, outcome definition and
   loss for both models. These specify existing unit/validation requirements,
   not a new effect threshold or automatic model acceptance.

## Consequence for experimental development

The drafts can now be discussed at the level of exact evidence decisions and
measurement choices. [Assay qualification](ASSAY_QUALIFICATION.md) sets out
what must be demonstrated in the actual model before any bench-ready label.
Meaningful effect, between-unit variance, actual access and owner scientific
acceptance remain unknown. No test is expanded merely to recover a positive result.
