# A13: research development dossier

Do fibroblast programmes add information about epithelial plasticity beyond macrophage IL1B?

Status: proposed refinement, 3 October 2026. This is a development aid, not scientific acceptance or an experimental protocol.

## Biological problem

Does a specified fibroblast output alter epithelial recovery at comparable inflammatory input, beyond differences in fibroblast abundance?

## Established knowledge

Fibroblast inflammatory, matrix and trophic functions differ. Published niche studies already support mesenchymal contributions to epithelial repair and reciprocal epithelial–fibroblast effects. A specific source output and its added explanatory value are needed.

## Repository evidence

The twelve-triad pilot using a fibroblast TGF hallmark and epithelial HPCS proxy worsened RMSE; all models performed poorly against baseline. It did not test feedback or establish that every fibroblast niche programme is uninformative.

## Unresolved gap

The failed TGF-hallmark/HPCS proxy model does not identify a fibroblast output that changes epithelial recovery beyond shared inflammatory context. No mediator is presently nominated by this dossier.

## Working hypothesis

A specified fibroblast output changes epithelial recovery under comparable inflammatory input through altered source activity, rather than merely a change in the number of surviving support cells.

## Competing explanations

Inflammation independently drives both compartments; fibroblast abundance or survival changes total support; the selected transcript score does not measure the relevant output.

## Discriminating outcomes

A validated change in the specified fibroblast output linked to a change in epithelial recovery under an interpretable source-directed contrast would support an additional niche contribution. An effect tracking source depletion alone leaves activity-specific attribution unresolved. RNA correlation alone does not decide either route.

## Next investigation

Retain the negative twelve-triad model. First identify a candidate functional source output from primary evidence and qualify source/recipient attribution and timing. If none is defensible, hold mechanism testing rather than choose a new score to rescue the model.

## Experimental bridge

A future source-directed comparison needs fibroblast viability and output measurements plus a separately measured epithelial recovery endpoint and interpretable inflammatory input. A13 concerns fibroblast-to-epithelium contribution; A22 retains epithelial-to-fibroblast chemokine regulation.

## Interpretation boundary

The failed model is neither a feedback test nor evidence against all fibroblast contributions; a new score cannot retroactively rescue it.

## Decision and maturity

Mechanism-development candidate with no selected mediator. Original negative result retained. Source-output qualification is required before a new contract; no claim acceptance or experimental readiness is inferred.

## Primary-source and feasibility review

The direction is restored to fibroblast output affecting epithelial recovery. A mediator must be justified before a new functional branch; A22 owns the opposite signaling direction.
