# A3 extension from the Nb5 normal-age reference

3 October 2026. Added after the owner-authorized Nb5 scientific review. This is
a proposed extension of A3, not a new RQ, accepted mechanism or completed model.

## Biological question and decision

Does a nominated lung macrophage programme associated with prior injury remain
distinct from its normal-age pattern within comparable origin/state and present
context? Nb5 supplies a reference for an existing rival. No distinct macrophage
subset or new functional consequence was nominated, so the same A3 question
owns this comparison. A future genuinely different subset/target can justify
separate registration under the owner's heterogeneity instruction.

## Evidence and strongest rival

The normal-age atlas comparison is exposed. A3's W1 remains pseudobulk, not
Compass; age/processing confounding, negative CAMERA findings and the ineligible
ornithine set persist. Age, origin replacement, ongoing context and processing
can explain apparent persistence without intrinsic memory. The Niethamer
source and the ageing atlas are separate study contexts, not a matched experiment.

## Unit and discriminating endpoint

Use animal within study and a fixed, independently nominated macrophage RNA
programme in a common state; do not define identity from the programme under
test. A supported history association after a genuinely identifying comparison
would motivate a separate functional question. Loss under age/origin/context
restriction favors the rival; imprecision remains inconclusive. RNA alone
cannot establish flux, secretion, trained immunity or repair.

## Extension sequence and holds

1. Nominate the programme and biological consequence without replacing negative
   pathway findings by a favorable search result.
2. Qualify common macrophage identities, animals, age, history, processing and
   present context in each source. Angelidis/GSE124872 is a possible independent
   normal-age reference, not an identifying history contrast by itself.
3. If age/history is confounded with study, stop the cross-study causal fit.
   Preserve study-specific descriptive comparisons and the unresolved rival.
4. Only an eligible numerical question proceeds through a new frozen A3
   contract. No analysis was run by this documentation extension.

Actual functional assay, effect margin, variance, sample size and independent
history-matched material remain unresolved. This concerns existing host-cell
data and a conceptual comparison, without an exposure procedure.
