# Research development index

All 24 current questions remain available. No RQ is selected by this repair.
The canonical register owns question identity; these dossiers develop the missing
scientific discriminator and experimental bridge. A completed computational
analysis is not an experiment-ready hypothesis. Published background and
repository observations are separated in each dossier; novelty requires a
targeted primary-source review before commitment.

Use this sequence: establish the known result → identify the remaining gap →
state a hypothesis and strong rival → specify outcomes that separate them →
qualify measurements and independent units → freeze an appropriate analysis →
evaluate the result → design the experiment justified by that evidence.

No numerical effect margin, sample size or molecular mediator has been invented
to complete these records. The endpoint, measurement validity and source/lab
feasibility must supply those choices. Dossiers describe comparisons at the
scientific-design level; they are not laboratory procedures.

## Decision discipline

Document what evidence would advance, revise or stop a branch before running it.
Preserve negative results, failed eligibility and stronger published explanations.
Fit to a lab is a feasibility constraint, not evidence for the hypothesis.
Private PI/funding/outreach planning stays outside the public repository.

Follow [research governance](../RESEARCH_GOVERNANCE.md) and the
[machine-readable registry](../../analysis/research/registry.json) for execution.
