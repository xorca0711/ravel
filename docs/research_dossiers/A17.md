Do persistent founder differences help explain unequal mutant clone growth?

Status: proposed refinement, 3 October 2026. This is a development aid, not scientific acceptance or an experimental protocol.

## Biological problem

Do persistent founder differences improve prediction of mutant clone growth over switching, survival and measurement alternatives?

## Established knowledge

Unequal clone sizes can arise from persistent founder heterogeneity or stochastic processes. A simulator defect does not refute source lineage observations.

## Repository evidence

Source accounting covers 58 rows and 11 source mice. The deposited slow-loss branch is unreachable in its current simulator implementation; the corrected stochastic model comparison remains unrun.

## Unresolved gap

Competing model families have not been compared under common observations, biological units and held-out predictive criteria.

## Working hypothesis

Persistent differences inherited from founder lineages may contribute to unequal mutant clone growth beyond reversible state switching and observation effects. A fitted founder class is a latent model term, not a discovered cell type. The current comparison concerns detected clone-size distributions until ascertainment and longitudinal linkage are qualified; numerical solver and identifiability work remain unfinished.

**Specificity/novelty disposition:** Model comparison; technical qualification unfinished. Clone growth heterogeneity is published. A scientifically identifiable founder-versus-switching comparison could add explanatory value; correcting a local simulator or fitting an extra class does not establish a new mechanism. See the [source comparison](NOVELTY_SPECIFICITY_APPLICATION_2026-10-03.md#a17). This is a proposed research scope, not a claim-grade or retain/reject decision.

## Competing explanations

State switching, differential survival, clone merger or observation error accounts for apparent founder persistence.

## Discriminating outcomes

A founder component that improves held-out prediction under comparably flexible switching/observation models supports that explanation only where identifiable. Equal adequacy or non-identifiability leaves the question unresolved. Unlinked size snapshots must not be called measured clone trajectories.

## Next investigation

Freeze competing model families, source-unit handling and identifiability diagnostics before a corrected fit. Preserve the original code defect and do not treat model fit as lineage proof.

## Experimental bridge

A lineage-resolved longitudinal comparison would require reliable clone identity and separate merger, loss and growth accounting. It should test a predictive difference that current measurements can actually resolve.

## Interpretation boundary

A fitted latent founder class is not a distinct biological cell type or a demonstrated molecular mechanism.
