# A6: research development dossier

Does IPF alter shared macrophage states beyond changing their abundance?

Status: proposed refinement, 3 October 2026. This is a development aid, not scientific acceptance or an experimental protocol.

## Biological problem

Which macrophage programme changes within shared states in IPF, and which measurable consequence would make that change biologically useful to explain?

## Established knowledge

Disease can change both state abundance and expression within states. These effects require separate estimands and adequate donor representation.

## Repository evidence

The proliferating-state comparison has only three IPF donors and one control at its gate. Earlier owner reservations about this direction remain recorded; registration does not reverse them.

Evidence locators (source citations and numerical details remain in these records):

- [Research Article/gate1_04_sikkema_2023_hlca/README.md](../../Research%20Article/gate1_04_sikkema_2023_hlca/README.md)

## Unresolved gap

There is no adequately supported within-state effector and recipient consequence that warrants a broad mechanistic claim.

## Working hypothesis

A named effector programme changes within a shared macrophage state and is associated with a specified tissue response beyond state abundance.

## Competing explanations

Disease differences reflect mixture, sparse controls or state-definition shifts rather than altered activity of comparable macrophages.

## Discriminating outcomes

A donor-replicated within-state effect with an independently measured consequence supports the hypothesis; abundance-only change or unstable donor estimates favors the rival.

## Next investigation

First assess donor eligibility and nominate a specific effector from source-grounded evidence. Stop if controls cannot support the contrast; do not expand gene-set screening to compensate.

## Experimental bridge

A later functional comparison would test the nominated macrophage output against a defined recipient response, with abundance and viability measured independently.

## Interpretation boundary

Cell count is not donor count, and within-state RNA difference is not an effector mechanism.

## Decision and maturity

Retain as deferred development with the earlier owner decision visible. No priority promotion or new broad search is implied.

Novelty remains provisional: review primary literature around the actual discriminator before calling this a new contribution. Assay validity, meaningful effect size, biological-unit variance and model feasibility must be established before a confirmatory experiment.
