# Cut unsupported claims; fill only decision-changing gaps

3 November 2026. Owner-requested follow-through to the
[33-question trajectory audit](README.md). This is an **analysis-plan artifact**,
not an executable contract or a new result. Existing question identities,
hypotheses, figures, unfavorable outcomes and frozen analyses remain intact.
The plan defines what to remove from the affirmative interpretation, what not
to repeat on unchanged inputs, and what evidence could reopen a comparison.

## Decisions now

- **Cut the claim when the evidence already fails to support it.** Do not run
  another analysis merely to justify removing an overclaim. A11's capacity
  diagnostic and the A29/A30 corrections already supply that decision.
- **Close spent branches on existing inputs.** A0 transfer, A10 repeated
  within-screen prediction, A11 same-eight-patient rescue fits, A13 proxy
  expansion, A22 broad identity retuning and A23 replacement compensation
  scores do not enter a new execution queue. This closes those routes, not the
  whole biological question.
- **Allow a bounded fill when a specified result changes a specified decision.**
  Five packages below address A5, A12, A17, A25 and A30. None is declared ready
  for numerical execution here. Each must first clear its particular entry gate.
- **Request new measurements rather than substitute more RNA.** A1/A8/A14,
  A20/A31/A32 and the other functional questions retain their named missing
  discriminator. A source qualification can proceed when an actual new source
  or accessible model is identified; an unlinked atlas is not a replacement.

No RQ is retired and no human scientific acceptance is manufactured. These
actions govern this requested follow-through, not repository-wide policy.
Historical statements remain visibly historical; their corrected interpretation
is linked from every question home.

## Questions that need a different measurement

For A1/A8/A14, the enabling record is one concrete early-feature/exposure and
later-output relationship with compatible units; the existing inventory should
be reused. For A20, the actual Fzd2/Fzd1 functional comparison is missing. For
A31, the expression premise is already sufficiently described to ask about a
direct response; more atlas expression does not measure it. For A32, source
identity and joint matrix/mature-output linkage remain missing. The same logic
applies to the other per-row functional or temporal gaps above.

A feasible donor/preparation comparison may use matched parallel aliquots for
destructive measurements when their relationship is valid and explicit; the
plan does not require repeatedly measuring the same destroyed cell. A valid
perturbation/control comparison can answer its stated effect question without
a mandatory rescue or factorial design. Conversely, the existence of separate
figures in one paper does not establish the required join.

No wet-laboratory protocol, target optimization, sample size or host capability
is supplied here. A literature/model-access check becomes useful when there is
a concrete source or laboratory opportunity. Without one, the truthful output
is the specific missing measurement, not another RNA mechanism narrative.

## Execution, interpretation and closeout rules

Every fill retains its original A owner and prior outcome exposure. Before a
numerical run, the technical worker must supply the exact data/code/reference
versions and hashes; independent units and joins; populations/comparators;
primary endpoint/scale/method; permitted sensitivities and multiplicity;
validity gates; and supported/unsupported/inconclusive decision rules. Unknown
effect margins and precision stay unknown. A source-version or reference-build
change requires explicit mapping rather than silently mixing annotations.

Use the existing contract, review/freeze and runner process. Each package gets
one declared primary comparison and its prospective sensitivities; an unfavorable
result does not automatically open more models or signatures. Error correction
remains permissible in a new preserved version. No numerical run is authorized
by a passing documentation check alone, and this plan registers no fake run.

The deliverable for a later package is a result **or a specific closed/held
disposition**, with the claim affected, evidence, reason and exact reopening
condition. Current capability and source unknowns are explicit above. This
follow-through completes planning and visible claim-boundary navigation; it
does not mark the five analyses completed.
