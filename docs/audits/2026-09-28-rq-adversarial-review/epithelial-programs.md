# Adversarial review: epithelial programmes (A0, A1, A5, A7, A8)

Review date: 28 September 2026. Baseline: checked-out `bbfa4e76` on `main`; this memo does not describe the newer locally recorded remote-tracking branch as checked-out or live upstream state. Scope: the five register cards, their specified workspaces, the A5 side of the shared A5/A11 contract, and their load-bearing M-series/ES1 precursors. No scientific fit was rerun, frozen output changed, or claim grade reassigned. Reports were checked against configurations, selected implementation paths and output tables; this is a targeted scientific and implementation audit, not a fresh raw-data reproduction.

**The principal gap is experimental identification, not a shortage of robustness plots.** A5 has a defensible externally defined RNA association. A0 completed a negative operational transfer test. A1 has valuable separate regulatory, perturbation and descendant observations but no replicated linkage that answers its central added-information question. A7 remains conditional on genotype-sensitive selection, and A8 has no independent mature-AT1 endpoint. More scores on the existing pooled multiomes would not fill those gaps.

In this memo, a **confirmed limitation** is directly supported by the reviewed design/code/table. A **risk** is an alternative explanation that has not been shown to drive the result. Proposed gates are new-work recommendations, not amendments to completed frozen trials.

## A0 — conserve a testable claim rather than an indefinitely elastic hypothesis

**Verdict:** the specified transfer prediction failed; the programme is not validated as a general transition programme. Keep the completed negative decision. A separate future hypothesis would need a reason for the selected biological process and an outcome that can falsify it.

**Confirmed limitations.** The scientific pilot selects genes using lung repair and an early human distal-to-proximal airway axis, then asks for an intermediate peak in mouse intestinal enterocyte commitment. Those are different lineages, anatomical contexts and life stages. The primary report explicitly states that late progenitors are not exclusively proximal and that the arrows are not individual lineage traces ([PILOT_V1_RESULTS.md:27](../../../RQ_Specified/A0_conserved_epithelial_transition_program/reports/PILOT_V1_RESULTS.md)). This is a stringent operational conjunction; a universal process does not logically require the same 20–50 upregulated genes to peak in every intermediate. Conversely, a positive conjunction could reflect shared biosynthesis, cytoskeletal adaptation or assay properties without controlling fate.

The discovery code ranks genes by the smallest of four selected median effects ([12_discover_pilot.py:52](../../../RQ_Specified/A0_conserved_epithelial_transition_program/scripts/12_discover_pilot.py)); the transfer code implements within-cell tied percentile ranks ([13_transfer_pilot.py:57](../../../RQ_Specified/A0_conserved_epithelial_transition_program/scripts/13_transfer_pilot.py)). Selection uses pseudobulk abundance while evaluation uses sparse within-cell ranks. This is a declared measurement change, not a coding error, but it narrows the test to this instrument. Annotation-marker removal cannot erase broader expression-based clustering dependence. With three V1 mice, the sign/omission rule is not an equivalence or absence test ([result:101](../../../RQ_Specified/A0_conserved_epithelial_transition_program/reports/PILOT_V1_RESULTS.md)).

The repair-first branch does not repair this: it reuses Strunz/Haber, uses a different programme/score and Negretti SCT data, and adds E3a after inspecting transfer ([exploratory report:21](../../../RQ_Specified/A0_conserved_epithelial_transition_program/reports/EXPLORATORY_PILOT_REPORT.md), [120](../../../RQ_Specified/A0_conserved_epithelial_transition_program/reports/EXPLORATORY_PILOT_REPORT.md), [159](../../../RQ_Specified/A0_conserved_epithelial_transition_program/reports/EXPLORATORY_PILOT_REPORT.md)). Its smaller control variant does not survive the proposed depth challenge robustly. Neither positive developmental description is an independent normal-development replication.

**Biological rationale challenged.** Sountoulidis supplies spatially organized developing airway states, which justifies the axis but not common ancestry with an alveolar-repair state or identical cell work. Spatial position and transcriptomic ordering remain indirect evidence for the role assigned to each cell. [Primary atlas](https://www.nature.com/articles/s41556-022-01064-x). The leading rivals are tissue-specific differentiation programmes, mismatch between branch/state definitions, shared generic demands and measurement differences. None was established as the cause of failure.

**Strengths to retain:** both-endpoint comparisons; unit-level summaries; frozen ortholog/label exclusions; no post-failure module rescue; recorded source substitution; and genuine stopping after failed transfer. The many arithmetic checks verify execution, not universality.

**Gap-fill sequence:**

1. **No new fit now.** Preserve `STOP_PRIMARY_TRANSFER_NOT_SUPPORTED`; P4 remains pruned ([TRANSFER_EXECUTION.md:19](../../../RQ_Specified/A0_conserved_epithelial_transition_program/TRANSFER_EXECUTION.md)). Close the 50-gene transferable-signature objective.
2. **Gate any new proposal on a narrower biological prediction.** State which cellular process is predicted to recur, in which lineage direction and developmental/injury contexts, and why a frozen RNA instrument should measure it. Choose an independent normal-transition dataset with explicit cell→capture→animal/donor mapping, raw counts, independently supported start/intermediate/destination definitions and adequate per-unit coverage. Three units are a minimal gate, not a precision target. The previously failed Negretti/Haber mappings cannot be assumed fixed.
3. **If that gate passes, freeze one new test.** Estimand: equal-unit intermediate-minus-each-endpoint effects for the unchanged nominated instrument in the nominated population. Specify an assay-calibration control and a meaningful effect/precision rule before reading effects, plus externally defined stress/cycle and lineage-identity controls. If the exact old 50-gene programme is tested, call it an independent replication attempt; do not relearn it on the evaluation cohort.
4. **Decision:** support only the stated transport claim if both endpoint effects meet its predeclared meaningful-effect rule and controls remain evaluable. A precise exclusion retires that claim; wide intervals or failed identity/measurement gates are inconclusive. No cascade through alternative branches, sizes or regulatory models after failure. Fate modulation remains a separate, later linked-perturbation/outcome question.

## A1 — replace a many-assay catalogue with one decisive linked comparison

**Verdict:** strong evidence that convenient RNA labels do not determine a unique biological interpretation; no completed test that regulatory measurements add to RNA in explaining a matched fate or functional response. Distinct experiments triangulate the motivation, but cannot supply that estimand jointly.

**Confirmed limitations and attacks:**

- **IRE1:** ten independent mice and the correct unpaired batch/sex-adjusted model are real strengths ([08_fit_ire1.R:14](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/scripts/08_fit_ire1.R)). Nevertheless RiboTag is bulk ribosome-associated RNA at day 7. Composition, expression and translational loading can all change; the separate day-14 traced AGER endpoint is not paired validation ([first batch:71](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/reports/FIRST_BATCH_REPORT.md)). Four whole-family hits, no predefined marker/pathway significance and highly variable omission discovery counts do not establish a state-specific regulatory mechanism. Stable direction remains a lead, not a replicated result.
- **Direct marks:** 23 loci, two preparations and one parental line are not a DATP/PATS/ADI/ABI/HPCS taxonomy. Mark/H3 and CPM are relative measurements, not absolute chromatin occupancy ([second batch:120](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/reports/SECOND_BATCH_REPORT.md)). H3 adjustment reverses some raw effects; CDKN1A H3K27ac changes sign at an alternate promoter in one preparation ([robustness:10](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/reports/ROBUSTNESS_REPORT.md)). Selecting the favourable promoter afterwards would be outcome-driven. Methylation-domain overlap in one normal-culture donor is neither a replicated methylation effect nor an injury-state discriminator.
- **PATS:** reconstructed marker fractions have correct within-mouse denominators, but separate marker panels are not mutually exclusive fates and zero-denominator controls are undefined. Source histone peak-caller/scaling differences prevent an amplitude conclusion; standardized raw processing would still confound injury, sorting and state. This is why the expensive raw-processing branch was reasonably pruned.
- **HPCS:** animal IDs and harvest timing are resolved in the latest primary crosswalk, so the earlier claim that there are only anonymous sources is obsolete. The **design** problem persists: adding chase after library adds zero rank ([rank audit](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/tables/robustness_2026-09-25/hpcs/design_rank_audit.tsv)); current mScarlet remains absent ([continuation:57](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/reports/REGULATORY_FATE_REPORT.md)). Descendant label composition among retained trace-sorted cells is affected by differential survival, proliferation and sampling; it is not a transition probability. K12-stringent abstention is unequal across states and reuses the same classifier ([closure:118](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/reports/EVIDENCE_CLOSURE_REPORT.md)).
- **CD44:** eight verified mice make the paired contrasts and direct genotype-by-sort interaction estimable; code uses explicit mouse effects and the coefficient difference ([30_fit_cd44.R:15](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/scripts/30_fit_cd44.R)). This defeats the “different significance means interaction” shortcut. However CD44 gates remain mixtures, genotype baselines are absorbed by mouse, and the Sftpc interaction nearly disappears after omitting WT2 ([closure:96](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/reports/EVIDENCE_CLOSURE_REPORT.md)). RNA differences are not chromatin-mediated functional differences.
- **AP-1/Tsutsui/TP53:** the region contrast uses six mice, not 36 independent microscopy fields. Its exact exploratory permutation p is 0.10 ([output](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/tables/regulatory_fate/ap1_region_interaction.tsv)); opposite observed directions challenge a universal benefit but do not establish a population-level regional mechanism. HOPX acquisition is not mature gas-exchange function. Tsutsui's medium-switch differentiation and programme suppression use separate experiments ([continuation:156](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/reports/REGULATORY_FATE_REPORT.md)). Selected TP53 DE lists include opposing signs and cannot estimate an origin interaction without complete tested coefficients/counts.

**Biological rationale challenged.** Shared injury RNA is compatible with a continuum, multiple origins, changing mechanical demands, senescence-like stress, selection of survivors, or multiple routes to different destinations. A universal categorical taxonomy is an unnecessarily strong objective. Tsutsui's human induced-cell model provides an experimentally modifiable transitional programme, but the paper's model and outcome contexts do not turn every in-vivo RNA-similar population into the same state. [Primary study](https://www.nature.com/articles/s41467-026-68909-z). The valuable next hypothesis is **context-specific regulatory information beyond RNA**, with an independently measured endpoint.

**Gap-fill sequence:**

1. **Pick one context, two operational populations, one endpoint.** The present plan's “reproducible direction” rule lacks a concrete endpoint increment and meaningful-effect bound ([PLAN.md:321](../../../RQ_Specified/A1_transitional_epithelial_state_distinction/PLAN.md)). Freeze those before expanding another modality. Use continuous regulatory variation if a state boundary cannot be independently justified.
2. **Input gate:** verified independent animals/donors, compatible mark/accessibility measurements, RNA from matched experimental units, explicit perturbation/region/time identities and a linked observed outcome. For prediction, the unit linkage must make “later” meaningful; separately sacrificed or unrelated cohorts supply triangulation only. For existing sources, exact TIGIT pool membership, PATS scale/control association or Tsutsui per-preparation normalized counts would unlock only their stated local contrasts, not the whole RQ.
3. **Primary estimand:** incremental held-out outcome performance of RNA+one frozen regulatory component versus RNA+time/region/technical covariates, or a prespecified regulatory contrast conditional on RNA similarity if only discrimination is feasible. Hold out whole animals/donors; perform any scaling, feature selection and tuning inside training folds. Evaluate discrimination and outcome prediction as different endpoints.
4. **Controls:** lineage origin, developmental age, region, survival/proliferation, generic stress and measurement quality; promoter identity and assay scaling; baseline outcome and cell-composition covariates when appropriate. Do not adjust away a mediator while claiming a total perturbation effect. Determine unit numbers from the desired precision, using current between-unit variance only as planning input.
5. **Success/failure/stop:** independent replication with an interval exceeding the frozen useful increment supports the particular discriminator. An interval excluding that increment retires it. Wide intervals, assay mismatch or rank deficiency hold the question. A causal claim needs an additional matched intervention/outcome design that can distinguish programme suppression from cell loss; no more pooled ATAC/IRE1 re-fitting to bypass this gate.

## A5 — a credible RNA recruitment result with unresolved developmental meaning

**Verdict:** retain partial recruitment of an externally sourced Guo P1 signature in Strunz ADI. The result does not yet show reuse of a developmental mechanism, lineage route or beneficial repair programme.

**Confirmed evidence:** all 24 primary mouse contrasts are positive; mean 0.735 detection percentage points, 95% CI 0.579–0.892. Identity-excluded and identity/control-excluded versions remain positive, with Holm adjustment ([inference table](../../../RQ_Specified/A5_developmental_programme_reuse/tables/test_v1/inference.tsv)). The script computes the exact expected detection after 500-UMI sampling and averages within mouse/state before pairing ([03_score_external_test.py:22](../../../RQ_Specified/A5_developmental_programme_reuse/scripts/03_score_external_test.py), [139](../../../RQ_Specified/A5_developmental_programme_reuse/scripts/03_score_external_test.py)). This is not cell-based pseudoreplication, a fold-change or a conversion fraction.

**Where the framing overreaches if expanded:** the old 94/51-gene variants use Strunz markers in their negative selection and cannot validate on Strunz. The new 99/57/53-gene definitions avoid that error ([PLAN.md:21](../../../RQ_Specified/A5_developmental_programme_reuse/PLAN.md)). The new result nevertheless inherits author expression-derived ADI/activated-AT2 labels, a sampled day-2–21 distribution and source QC. It estimates a conditional average in eligible mice, not an injury-time-invariant effect.

Removing genes in six Hallmarks establishes robustness to those **memberships**, not independence from stress signalling. Removing Guo top-100 AT1/AT2 list members does not exhaust alveolar maturation genes. Equal weight across remaining genes can also yield a positive mean without a coherent coordinated programme; a handful of high-contribution genes is a plausible risk, not a demonstrated defect. No arbitrary practical-effect threshold should be applied retrospectively to the 0.735-point result.

**Biological rivals:** Guo measured P1 birth adaptation, including stress/UPR; it identified mixed AT1/AT2 RNA and spatial co-detection, while progenitor fate was inferred rather than traced for each sequenced cell. Thus perinatal adaptation, epithelial remodelling, AT1-directed acquisition and generic stress remain live explanations. [Guo primary study](https://www.nature.com/articles/s41467-018-07770-1). Neonatal AT1-to-AT2 reprogramming reported by Penkala also makes a shared direction of lineage progression an unsafe assumption. [Primary publication record](https://pubmed.ncbi.nlm.nih.gov/33974915/). Strunz's reported weak global developmental correspondence is compatible with a positive small external subset; these are different estimands, not mutually cancelling observations. [Strunz study](https://www.nature.com/articles/s41467-020-17358-3).

**Gap-fill sequence:**

1. **Cheapest decisive next input:** a second adult-injury study with animal IDs, raw counts and enough independently defined transitional and activated-AT2 populations to apply the unchanged primary instrument. Require source→cell→animal mapping, primary ≥30 cells/state after the frozen depth threshold and source coverage; add a precision target above the minimal three-animal gate. If no such cohort qualifies, stop acquisition after a bounded shortlist and retain the current within-study claim.
2. **Freeze external replication:** equal-animal paired ADI-minus-activated-AT2 detection effect; retain the 99/57/53 definitions and their test family. Report time strata descriptively under a declared weighting rule, not selected-day successes. Predeclare a gene-contribution/concentration diagnostic and independent state-label sensitivity. No choice of genes or labels based on the desired replication sign.
3. **Resolve developmental meaning separately:** require an independent normal-development cohort, with actual animal/donor identities and relevant endpoint/intermediate coverage, to test whether the nominated component is enriched beyond both mature identities. Negretti's recovered viewer does not solve its missing unit map or sparse triplets. Include birth-adaptation/stress controls and a later-development comparison only if the design supports them; do not convert age into pseudoreplicate identity.
4. **Decision:** replicated positive external association supports transport of recruitment; a precise negative or negligible effect limits it to the original context. Positive recruitment in both settings still is not shared mechanism. Only after this should a linked outcome/perturbation study ask whether component variation improves mature tissue contribution, persistence or another prespecified endpoint. Do not build the experiment around the machine label `development_specific`, which means list exclusivity only.

The A5/A11 contract remains useful for provenance, but it contains two disjoint pairwise overlaps. Four of five development–injury genes also match a published AT1 identity list, while the injury–lesion component includes stress-associated genes ([stage 2 report:27](../../../RQ_Specified/A5_A11_shared_component_contract/reports/STAGE2_3_REPORT.md)). Neither “shared remodelling” nor “specific” is an independently validated biological mechanism. A11's patient results are reviewed separately.

## A7 — the selection rule is entangled with the proposed genotype effect

**Verdict:** the smaller labelled–reference contrast is real as an ES1 conditional description. It cannot distinguish broad identity attenuation, state-specific regulation and genotype-dependent admission to either group.

**Confirmed design problem:** before scores, ES1 retains cells using Sftpc/Sftpb/Lamp3 versus airway expression; reference assignment then requires Sftpc detection, while the labelled group requires Cldn4/Krt8 ([run_es1.py:82](../../../Research%20Article/epithelial_state_specificity/run_es1.py)). Removing Sftpc/Cebpa from the score avoids direct self-inclusion but does not remove selection on correlated identity. A genotype that changes identity can change which cells survive the screen and reference rule. The two groups need not represent comparable biological populations between genotypes. Fixed total UMI also makes detection contrasts compositional; it controls depth, not every change in transcriptome allocation.

One pooled library per condition prevents a replicated genotype interaction. Technical seeds change group membership and do not add mice. Source naming also inherits the historical marker-corroborated suffix map; an independent experimental crosswalk remains the right gate for a new confirmatory analysis. These do not prove that the recorded genotype direction is wrong.

**Biological rationale/novelty:** the broad proposition that CEBPA sustains AT2 identity is already central to the 2024 primary study. [Primary paper](https://www.nature.com/articles/s41467-024-48632-3). Sawhney et al. additionally report Cebpa loss associated with reparative and defensive AT2 states, making a single broad-versus-transitional binary incomplete. [2025 primary study](https://www.nature.com/articles/s41467-025-64224-1). The new contribution should quantify how much change occurs within comparable states versus through state occupancy, with age and injury context specified. Reduced AT2 identity need not mean repair failure; the direction of tissue contribution must be measured separately.

**Gap-fill sequence:**

1. **Gate:** independent genotype-matched mice at the same age/injury interval; an experiment-backed sample/genotype map; pre-existing lineage identity or an external state definition that does not require current Sftpc or scored identity genes. Record excluded/unassigned lineage cells rather than silently dropping them. GSE295269 is a source-listed perinatal Cebpa candidate, **not yet eligible**; audit its animal/pool map and available states before fitting. [GEO record](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE295269).
2. **Freeze two estimands:** genotype effects in fixed externally defined states and their direct interaction; separately, genotype-associated state abundance and total traced-lineage identity. Because state itself can change after genotype perturbation, conditional state effects must not be represented as the total causal effect.
3. **Controls:** age, injury, source preparation, RNA quality/depth, recombination/lineage specificity and reference selection. Include a prespecified defensive-state alternative if justified independently; do not discover that subgroup by searching for the largest genotype interaction.
4. **Decision:** broad attenuation requires concordant meaningful shifts in both states plus a sufficiently precise interaction bound. A meaningful replicated interaction supports a state-selective component; both can coexist. A nonsignificant interaction does not establish equality. If state definition or independent replication fails, stop at description. No additional random seeds or cell-level p-values can pass that gate.

## A8 — an overlap diagnostic is not a maturation hypothesis test

**Verdict:** A8 is an important measurement problem with very little direct biological support. The 119-gene ADI/AT1 overlap proves dependence of those instruments, not that transition causes mature fate or that a disjoint residual measures maturation.

**Confirmed limitations:** ES1's late panel is only Aqp5, Vegfa, Cav1 and Spock2 ([modules.json:42](../../../Research%20Article/epithelial_state_specificity/modules.json)); observed technical sign sensitivity makes it a weak instrument for a new primary endpoint. The experiments have no independently measured mature-AT1 tissue contribution joined to those scores. A1's PATS AGER and AP-1 HOPX source endpoints are informative candidates, but are separate assays/experiments, with protein acquisition rather than full mature function. Neither an RNA score nor the fraction of endpoint-labelled cells alone measures total mature surface contribution.

**Rivals:** maturation timing, altered cell survival, intermediate residence time, different lineage origins, cell size/shape and tissue sampling can change an AT1-related signal. Disjoint gene sets can remain biologically and technically correlated, and deleting all overlapping genes can discard genuine maturation biology. The goal is independent measurement and transport, not zero gene overlap at any cost.

**Gap-fill sequence:**

1. **Endpoint gate first:** nominate one mature endpoint with a clear denominator—e.g. independently scored mature phenotype/tissue contribution among a traced lineage—and require animal/donor identities and a valid link to the predictor measurement. Retain total lineage abundance or absolute contribution alongside descendant fractions so survival/expansion cannot masquerade as differentiation. If predicting later outcome, specify the actual temporal/unit linkage; separate sacrificed cohorts cannot supply same-cell prospective prediction.
2. **Freeze an external instrument:** nominate shared and maturation-enriched components from data independent of the endpoint evaluation cohort. Audit membership, direction, assay coverage and technical repeatability before primary evaluation. A new component or a four-gene panel tuned on these outcomes is discovery and needs a separate test set.
3. **Primary estimand:** improvement in whole-animal/donor held-out error or explained outcome variation when adding the maturation component to shared transition, time, origin and quality. Use all transformations and tuning within training folds; compare with the same baseline on the same held-out units. Test a primary endpoint, not several retrospectively chosen mature markers.
4. **Decision:** a prespecified useful increment with independent replication supports added information for that endpoint. A precise exclusion weakens the nominated component, not all maturation biology. Wide intervals, unstable scoring or absent endpoint linkage are inconclusive. Do not run another broad AT1-score correlation on ES1 as gap fill. Mechanistic necessity requires a separate intervention question.

## Investment order and remaining uncertainties

1. **A5 external cohort eligibility** is the clearest near-term replication opportunity: instrument and estimand already exist. Prioritize a bounded identity/coverage audit over more scores in Strunz.
2. **A1 and A8 should share an endpoint-acquisition gate**, not duplicate source searches. Choose a single assay-compatible context with an actual outcome linkage. Keep assay-specific questions separate from a universal taxonomy.
3. **A7 needs independent state and genotype identities before inference.** Audit an external cohort and sharpen novelty to within-state versus occupancy effects; do not repeat the already established general CEBPA identity claim.
4. **A0 requires no completion analysis.** Archive the decision as complete-negative and only open a different, narrower proposal if independently justified.

Unresolved possibilities include ambient RNA/doublets, signature concentration in a few genes, selection-induced genotype differences and cross-platform score behaviour. They are plausible rivals, not confirmed explanations of the results. Current source availability, raw alignment QC and unpublished animal mappings were not exhaustively re-established. The parent review's baseline repository validation is reused; this memo required no new model tests. The essential spending rule is to pay first for an input that changes identifiability, not for another technically correct analysis of the same insufficient design.
