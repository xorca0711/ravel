# Research questions: adversarial review and gap-fill plan

**Date:** 28 September 2026. **Status:** review complete; proposed corrections and research plans are not executed.

The repository supports several defensible, narrow RNA associations and valuable negative decisions. It does **not** yet establish a common mechanism linking transitional RNA, regulatory state, niche signals and functional repair. The main limitation is identification of the biological comparison: independent units, comparable cell populations, temporal linkage and measured outcomes. Repeated sensitivity analyses on the same cohorts cannot supply those missing observations.

The strongest current candidates for further scientific investment are **A5 external replication, A12 independent epithelial validation, A11 identity/comparator resolution, and a shared A1/A8/A14 regulatory-to-outcome design**. This is a priority order, not a proposal to discard the remaining RQ identifiers. The most urgent code repair is an incorrectly implemented **A15 alternative-normalization sensitivity**.

## Recommended execution sequence

1. **Repair evidence interpretation and the one verified code defect.** Append the A15 normalization correction with a versioned sensitivity and independent invariant check; propose C49 wording correction; place the acute paragraph under A11. Reconcile with the locally newer branch before touching status files. Deliverable: a small correction set with a clear affected/unaffected result map, not new biological claims.
2. **Finish decision-changing metadata gates.** Resolve A5 independent state/mouse correspondence; A10 preparation and imaging mappings; A11 comparable epithelial identity; A12-S1 unknown-cell identity. Each request must specify the exact field or observation needed. Do not run another model merely because a large matrix is already downloaded.
3. **Run at most one unchanged external validation per promising prediction.** A5 external RNA recruitment and A12 epithelial prediction are the leading candidates. Choose the endpoint, population and useful effect/loss margin before validation. Declare cohort exposure and freeze all learned preprocessing. A11 needs its comparator/identity gate first. Passing cell/donor floors alone never guarantees power.
4. **Build one outcome-linked research programme.** Share sourcing across A1/A8/A14 but retain separate estimands: early regulation beyond RNA, mature contribution, and recipient-dependent recovery. An available compatible dataset may suffice; do not assume every gap requires a new experiment. A3/A4/A7 need their distinct age/history/genotype designs, so cannot simply inherit this dataset's validity.
5. **Advance mechanism only with discriminating evidence.** A2/A9/A15 should separate source, presentation, receptor state and active ligand with suitable independent measurements. A13's current predictor has no reason for further tuning. Preserve A0 P4 pruning and the owner's A6 priority decision.

For every new task, the launch record should state: the decision that can change, independent unit and source identity, predictor/endpoint timing, untouched validation unit, primary comparator, useful margin and expected precision, and the exact stop condition. These are prospective requirements. They must not be retroactively attached to completed trials as if preregistered.
