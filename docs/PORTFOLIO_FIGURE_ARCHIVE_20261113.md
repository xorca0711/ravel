# Public-data portfolio figure archive

13 November 2026. The owner requested publication of approved figures created during portfolio preparation for Nabhan, Saxton, DuPage and Wagner. G-SURF microscopy remains private. CVs, cover letters, personal plans and rejected figure drafts are not included.

## Scope and provenance

This is a byte-preserving import of previously generated displays, not a numerical rerun. All outcomes were already exposed. Each group has a frozen metadata contract, an exact input hash list, an execution receipt and a portable figure manifest. Display changes do not strengthen the source claims.

The Peeters chromatin extensions were frozen in a separate local worktree and were not in the integration base. The archive includes the existing display inputs and portable upstream run records. This import does not claim that their original scientific execution bundle has been merged or independently replicated.

Saxton IL-22/IL-10 and Gorby source figures already present in the repository are linked through their original article galleries. New combined displays and the missing experimental-structure renderings are archived here. Navarro/Canaria scientific figure regions were exported from the approved document at 288 dpi; no private pages were exported.
