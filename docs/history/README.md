# Documentation history by purpose

These records preserve completed reviews, earlier proposals and prior handoffs.
Their dates, counts and next steps describe their original checkpoints. Start
current work from the [documentation index](../README.md), the owning question
or article report, and the [source register](../DATASETS.md).

| Purpose | Location | What belongs here |
|---|---|---|
| Earlier plans and deferred-work ledgers | [planning](planning/README.md) | Superseded repository roadmaps, dataset gates and completion ledgers |
| Completed editorial and framing reviews | [reviews](reviews/README.md) | Dated proposals, alignment checks and figure/documentation reviews |
| Earlier source-list updates | [source inventories](source-inventories/README.md) | Supplements incorporated into the single current source register |
| Agent-entry and handoff snapshots | [2 November navigation snapshot](2026-11-02-navigation-hygiene/AI_CONTEXT.md), [progress snapshot](2026-11-02-navigation-hygiene/PROGRESS.md), [pre-governance locator](2026-10-03-pre-governance/README.md) | Prior context; no second current status register |

Other records already have purpose-specific homes and retain their stable paths:

| Existing collection | Purpose and preservation rule |
|---|---|
| [audits](../audits/) | Dated inspections, validation results and provenance manifests; retain evidence and original snapshot counts |
| [research reviews](../research_reviews/) | Literature, framing and source qualification; some specifications are hash-bound inputs, so they stay in place |
| [roadmap runs](../roadmap_runs/) | Executed historical work and source recovery, including data tables and scripts; not an active execution queue |
| [portfolio extensions](../portfolio_extensions/) | Prior portfolio synthesis and grouped extensions, with original evidence boundaries |
| [migrations](../migrations/) | Identity/layout transitions and preservation records |
| [handoffs](../handoffs/) | Dated task-specific handoffs |
| [dossier packages](../research_dossiers/packages_2026-10-03/README.md) | Historical conditional packages; current question reports supply later results |

Compatibility links remain at a small number of former paths used by frozen
evidence, contracts or generated reports. They contain only a destination link;
the full document lives in its category folder. The
[move record](../audits/2026-11-08-source-consolidation/document_moves.json)
records each destination and the consumers that require a stable old path.
No historical evidence or unresolved question was deleted as unused.
