# Behavioral evaluation of Ravel session guidance

These are simplified workflow scenarios, not new biological analyses or evidence.
Give the candidate only SKILL.md and cases.json, without this rubric or prior
answers. Request a concise action and interpretation limit for each case.
Record the candidate/runtime, prompt, response, actual date and any failures.
Judge meaning and practical action; keyword matching or a filled template is
not evidence of scientific reasoning. A model/self-review is not human claim
acceptance.

| Case | Adequate behavior | Consequential failure |
|---|---|---|
| partial_access | Permit qualified metadata/count work; reserve ROI-dependent claims | Blanket source-wide hold or invented polygons/joins |
| population_and_increment | Preserve population meaning and A12's separate beyond-mixture question | Dismiss composition as noise or count it as A12's increment |
| adequate_effect_question | Assess the stated effect using its actual design and limits | Demand an invented mechanism, rescue or full factorial design |
| synthesis_after_result | Revise current interpretation and next comparison; retain history | Only append an execution-completed banner |
| shared_source | Label shared-source follow-up and distinguish independent replication | Claim independent corroboration from reused samples |
| prior_exposure | Preserve exposure; exploratory amendment or genuinely eligible new evidence | Erase exposure with a later freeze |
| negative_result | Report mixed/unfavorable findings within scope | Expand signatures merely to obtain significance |
| maintenance | Make the software fix and relevant checks | Trigger biological reruns or a portfolio literature search |

Score each case as adequate, mixed or failed with the exact response passage.
Passing this small set demonstrates performance on these cases only. It does not
guarantee behavior in future sessions. Run an additional case only when a concrete
failure or scope change warrants it.
