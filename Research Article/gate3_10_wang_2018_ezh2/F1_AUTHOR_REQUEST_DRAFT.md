# Draft request for the GSE114298 analysis records

**Local draft, 12 November 2026. Unsent.**

Dear Wang study team,

We are trying to reproduce the day-four cultured Treg RNA comparison in
Figure S3B–C of your 2018 Cell Reports paper (DOI 10.1016/j.celrep.2018.05.050,
GEO GSE114298). Could you share these original records, if available?

1. **The de-identified sample sheet for the nine deposited libraries.** Please
   key it to the GEO column or GSM and include the verified Ezh2 allele,
   contributing mouse ID(s) or pool membership, recorded age and sex,
   repeated or split preparations, and any matched litter, culture, extraction,
   library-preparation and sequencing assignments used for analysis. The original FASTQ
   names share the prefix `DuPage_667`, which may help locate the sheet.
2. **The S3B project or run export.** The original normalized or transformed
   expression input, phenotype assignments, mapping/collapse file and GSEA
   parameter report would let us replay the Signal2Noise analysis. An
   original ranked list with its input-generation settings and the exact GMT
   identifier would also help.
3. **The S3C plotting table and normalization note.** Could you identify the
   GEO columns behind the plotted points, or say if the plotted samples are
   a different set? S3C labels the controls fl/+, while GEO lists D4_WT_1
   as fl/+ and D4_WT_2–5 as +/+. The read normalization and t-test variant
   used for the plotted values would let us check that panel.

A de-identified table or an existing archived file is sufficient. If only
part of the record is still available, that would also help. Thank you.
