# M24 accessibility at distal epidermal Memory and Resolved regions

**Step 3 setup for coordinator review.** Nk17-P01, 19 November 2026. The question is whether the previously selected Memory and Resolved classes show different post-IMQ versus naïve coverage at M24. The late time did not select the regions. Cowley Fig. 1 already displayed late trajectories and the team reused the same study. This is an exposed, finite description of four pooled libraries. ## Primary comparison

Use all **791 distal Memory and 784 distal Resolved** intervals from the governed manifest. S2 deposited 934 Memory and 933 Resolved regions before excluding intervals that overlap any GENCODE M9 transcript TSS ±2 kb on chr1–19/X. Retain the deposited Resolved count. The four separate M24 fragment-CPM BigWigs are GSM9034861 and GSM9034862 (naïve) and GSM9034863 and GSM9034864 (post-IMQ). Each represents a pool of two or three mice according to the study. Pool membership and cross-group pairing remain unresolved. [Regions](../../../analysis/research/runs/naik2017_distal_m24_metadata_v1/regions.tsv) · [Libraries](../../../analysis/research/runs/naik2017_distal_m24_metadata_v1/samples.tsv)

1. For each interval and pool, calculate the sum of per-base fragment CPM divided by the **entire interval width**. Within each pool, independently average those interval means across Memory and across Resolved, giving each region equal weight.
2. For each class, subtract the average of the two naïve pool values from the average of the two post-IMQ pool values. The primary contrast is the Memory change minus the Resolved change, in CPM. Equivalently, subtract the naïve mean within-pool Memory–Resolved gap from its post-IMQ counterpart. Both identities are checked.
3. Report each pool’s two class means and gap. Also report all four post-IMQ-pool minus naïve-pool contrasts for each class and its gap. They share pools and show descriptive spread. The two pools per group are the sampling units. There are no region-based tests or confidence intervals. A complementary table repeats the same pool-level arithmetic using the median of interval means within each class. This can reveal whether a small number of high-signal regions influence the mean.
4. Retain sign, heterogeneity, measured zeros and null differences. A positive gap change describes greater relative separation in post-IMQ pools. Similar class-specific changes can yield little gap change even if both classes shift. A negative value indicates a greater change for Resolved. Interpretation is limited by initial induction strength, sorted-cell composition, pooling and a single M24 experiment. Neither a small value nor a zero establishes equivalence, absence of memory, causality or repair function.

## One sensitivity using D6 induction and interval width

Compute quartiles (25%, 50%, 75%, linear interpolation, type 7) separately for published D6 IMQ-versus-control log2 fold change and interval width in bp, pooling all 1,575 eligible regions once. Use raw values. Each inner cut belongs to the higher bin, including ties crossing repeated cuts. Retain all 16 joint cells and the observed cut points, including empty cells. The region and source-class identity is fixed before any M24 query. D6 control abundance is unavailable. S3 baseMean includes later samples and is excluded from weighting.

For stratum *s*, let *mₛ* be the smaller of its two class counts. Set *M* to the sum of *mₛ* over the 16 strata. Each class gives stratum *s* the same total weight *mₛ/M*. Within a shared stratum, each member has weight `m_s / (M × n_sc)`, where `n_sc` is its class count in that stratum. No individual pair is selected. A region in a stratum missing either class has zero sensitivity weight and remains in the primary analysis. If *M* is zero, record unavailable common support and retain the full-cohort results. Repeat the pool means and contrasts using these weights.

The registered Step 2 covariate table already fixes the numerical design. D6 inner cuts are 1.2247967800000001, 1.981410939 and 2.848257298. Width cuts are 466, 631 and 851 bp. Summing the Step 2 three-variable cell counts over baseMean recovers the two-variable design without conditioning on baseMean. The stratum masses, by ascending D6 quartile and then width quartile, are **(16,18,16,35), (25,29,54,26), (48,52,34,19), (34,35,17,11)**. Divide by 469 for the frozen class-shared stratum weights. Every cell has both classes. All 791 and 784 regions remain represented, with regional Kish effective sizes 597.47 and 588.55. The execution checks every cut and cell count against the registered table before opening a track. These values were obtained from previously qualified covariate metadata alone. [Registered support table](../../../analysis/research/runs/naik2017_distal_m24_metadata_v1/region_qualification.json)

Report all region weights, cell/class counts, per-class retained and excluded region counts, *M*, and regional effective sample size 1/Σw² within each class. Report D6 strength and width means by class and their signed Memory–Resolved differences before and after weighting. Standardize both differences with the same full-cohort pooled within-class sample SD. A zero SD gives an undefined standardized difference. These diagnostics describe overlap and residual imbalance in two observed covariates. They do not control true baseline accessibility or add animal replication.

## Exact coverage and stop condition

The standard runner binds every raw BigWig SHA-256. Before any primary query, the reader rechecks complete bytes/hashes and chromosome dictionaries for all four files against Step 2. For each of 6,300 region–library combinations, clip all exact stored records to the requested half-open bounds, mark occupancy independently of value, and reconcile the reconstructed array base-for-base with an unbinned pybbi fetch (`bins=-1`, NaN missing sentinel, separate out-of-bounds sentinel). Use the complete float64 sum divided by width only after exact equality and full coverage. The native file’s global covered-base field and zoom summaries never supply values or denominators. [Reader](m24_reader.py) · [Qualified structure](../../../analysis/research/runs/naik2017_distal_m24_metadata_v1/track_structure.json)

Explicit zero occupies a base. Absent bases, overlapping records (including identical overlaps), conflicting values, nonfinite or negative record values, invalid bounds, wrong fetch length, pointwise disagreement and read failures have diagnostic fields. If any eligible interval fails in any pool, write all obtainable interval diagnostics and counts and stop before all class summaries, contrasts and figures. A pre-query file/header failure records its stage. Do not replace a missing or failed value with zero, drop the interval, or renormalize a cohort. The standard runner preserves an unsuccessful attempt for review.
