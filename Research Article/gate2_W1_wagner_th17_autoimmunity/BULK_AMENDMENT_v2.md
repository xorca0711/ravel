# R3 descriptive version 2: explicit gene-identifier binding

The first descriptive run stopped before any biological expression contrast because the twelve mouse-style display names did not literally match the uppercase symbols in both deposits. Identifier-only inspection establishes that all twelve original genes exist uniquely under their exact uppercase symbols.

Version 2 binds those names explicitly and writes `gene_identity_map.tsv`. It does not substitute genes, use an ortholog mapping, aggregate duplicate symbols, relax numeric checks or alter the statistical/normalization/display choices. All original genes remain displayed regardless of outcome. Version 1 and its failed receipt remain immutable.
