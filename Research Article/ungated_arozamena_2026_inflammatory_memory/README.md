## Comparison and interpretation limits

The tissue is intestinal epithelium. The actual history/time/lineage conditions,
comparison records, biological preparations, pooling and assay pairings must be
recovered before choosing numerical endpoints. Do not guess a baseline, an
injury-time contrast, a cell-state label or an independent animal from a file name.
Read the current source report before the original published interpretation.

Primary candidate measurements are source-qualified state proportions and
within-state RNA/accessibility summaries. The main alternatives are composition,
lineage selection/survival, library/processing effects, mismatched assays and
continued niche input. These can coexist with within-state differences. Gene
expression is not signal activity; accessibility is not occupancy or memory;
cell-level pairing is not independent biological replication. Later functional
outcomes require actual sample/animal/preparation joins, not shared group names.

The exact estimands, preprocessing, filtering, state mapping, peak/gene linking,
normalization, contrasts, multiplicity and sensitivity family will be specified
prospectively after source qualification. Unknown independent units restrict
analysis to appropriately labelled finite-library description. No population
p-values/FDR or certainty claims are authorized by a large cell count.
