## Generation and provenance

Each owning `schematics/` directory contains the selected PNG, exact prompt text
and retained initial `A*_comparison_v1.svg`. The SVG is the earlier conceptual
comparison draft for the same hypothesis; these PNGs were generated from the
recorded text specifications, not traced or rasterized from that SVG. A35's
selected prompt file records both generation and the narrow edit correcting its
single-strand RNA symbol and IGFBP4 colors. Unselected generated originals remain
in the local image-generation cache. No deterministic regeneration is claimed.

The registry binds the PNG, retained SVG, prompt, source revision and unchanged
full working hypothesis. Only the selected PNG is displayed in each question and
context page. The existing raster-provenance rules are used without changing
their validator or relaxing scientific-asset checks. This is an agent editorial
review, not independent human scientific approval or experimental evidence.
