# Nb5-P02 Microglial intermediate state and disease overlap

**Question:** Does the intermediate pattern highlighted in the owner's note
describe a reproducible within-microglia expression state, or a changing
mixture of endpoint states? The decision is whether a distinct state merits
independent functional characterization before an Alzheimer-related hypothesis.

**Working hypothesis:** A reproducible intermediate molecular configuration
exists beyond an age-dependent mixture. **Strongest rival:** Older and younger
endpoint populations change in proportion; integration, depth, stress or batch
creates apparent continuity. The source trajectory and disease overlap have
already been seen, so this is exploratory and outcome-exposed.

**Unit and endpoints:** Mouse; microglial cells are nested observations.
Report per-mouse candidate-state fraction, prespecified multigene contrasts and
out-of-mouse reproducibility of state assignment. Compare a continuous-state
description with an explicit mixture description using mouse-held-out error
where unit coverage permits. State definitions must not use the same disease
gene set later offered as independent support.

**Ordered tests:**

1. Qualify brain region, microglial identity, animal, age and processing.
   Distinguish infiltrating macrophages and uncertain cells using source-backed
   identities; do not force all myeloid cells into microglia.
2. Reconstruct deposited age/cluster and diversity summaries with their exact
   source definitions. Record source-label concordance separately from any new
   clustering. Assess animal contribution, cell-count sensitivity, depth,
   feature selection and a bounded resolution range fixed before execution.
3. Evaluate mixture and state descriptions on unintegrated expression and
   mouse-level summaries. Train transformations and state assignments only on
   training mice when reporting held-out performance. A visualization alone
   cannot decide the models. An internal holdout remains exposed validation.
4. Review the exact disease-associated-microglia precedent and qualify an
   independent, age-compatible disease/control cohort before any disease
   transfer. Define the measured-gene universe, signature version, overlap
   exclusion sensitivity and one declared overlap/enrichment family.
5. Retain the candidate only as a proposal if it is reproducible beyond
   mixture and technical explanations. If evidence supports a mixture, record
   that result. If age and batch are inseparable, stop inferential comparison.

**Limit and missing discriminator:** Cross-sectional state ordering does not
measure a cell's transition, reversibility or beneficial treatment direction.
A later design would need independently linked state changes and disease or
neuronal-function outcomes, with survival and starting composition accounted
for. Model access, assay validity, meaningful effects and precision are unknown;
no intervention target or treatment protocol is selected here.

**Additional-analysis frame:** compare per-mouse state occupancy and state/mixture
model adequacy. Keep the external disease-signature test separate from state
definition and label each source of shared gene-selection exposure.
