# Nb5 source reproduction scope

**Current execution:** see [results and amendments](RESULTS.md), [figures](FIGURES.md)
and [execution ledger](EXECUTION_VALIDATION.md). The planning text below records
pre-execution choices and is retained; it does not override current evidence.

Planned and unrun. This track checks source fidelity; the
[branch register](BRANCH_REGISTER.md) separately asks additional questions.
The [source note](NOTE_RECONCILIATION.md) identifies paper/supplement locations.
No exact panel contract is frozen and no source workbook has been inspected.

| Source anchor | Bounded reproduction task | Required input | Extra question belongs elsewhere |
|---|---|---|---|
| Figure 1 and Tables 1–3 | Reconcile animal/tissue/assay coverage and annotation totals | Exact release metadata, source tables and label definitions | P04/P07/P08 require new estimands beyond the coverage display |
| Figure 2 and Tables 4–6 | Reconstruct one fixed marker or composition panel with its original denominator | Source panel definition and corresponding cells/table | P01/P05 assess mixture and measurement explanations |
| Figure 4 and Table 10 | Reconstruct a fixed immune-state/diversity panel | Original labels, animal map, entropy definition and analysis settings | P02 asks whether state structure survives explicit rival models |
| Figure 4 and Table 9 | Reconcile repertoire totals and source-defined clonal fractions if assignments are available | Original clonotypes, assembly status and animal links | P06 examines sampling/compartment robustness |
| Liver staining and Table 7 | Optional source-table arithmetic only | Image-level and animal-level provenance | No new imaging measurement or functional reproduction is implied |
| Figure 3 and Table 8 | Record scope and inputs; no mutation-calling run in the initial queue | Sequence-level provenance and error controls for any later dedicated proposal | Expression matrices alone cannot test mutational burden |

Freeze the smallest source-panel subset that answers a stated verification
decision. Availability can select which panel is feasible before results;
agreement cannot be used to select which attempted panel is reported.

Record reproduction status per panel: exact at the verified release/method;
adapted with a stated changed estimand; table-only numerical reconstruction;
or held because inputs or identities are missing. Include mismatches and
uncertainty. Source p-values, animal-aware sensitivity and independent cohort
validation are three different evidence products.

An entire atlas, every paper figure or the owner's complete interpretation
must not be labeled reproduced after this bounded track. New research branches
receive separate contracts and reports even when they reuse the same inputs.
