# Nb2: receptor, state and duration in alveolar repair

**Question:** when does Fzd stimulation support differentiation-competent alveolar
repair, and when does its response reflect cell identity, persistent transition
or a different niche function?

The evidence consists of 18 source organoid libraries, a new 14-library
Stk3/4-loss/YAP-TAZ comparator, and sample/state aggregation of the existing
162,175-cell mouse object. There are 182 bulk program contrasts, five figure
pairs and explicit coverage/influence checks. Cells, genes and repeated
sensitivity settings never count as independent biological replicates.

The strongest immediate follow-up is a **state- and duration-resolved epithelial
comparison with linked later fate**, jointly serving N1–N3/N5. Fibroblast
subtype-specific receptor function is a separate niche question. Compensation
and capillary progenitor function need discriminating perturbation evidence.
The repository's repair-versus-remodeling purpose supplies the outcome question;
an RNA score does not supply that outcome by itself.
