# Nb2-N5 candidate: distinct routing or unequal response amplitude?

Paper-local interpretation draft. Not registered under `RQ_Specified`; its scope
may be merged, reframed or dropped after synthesis of the branch results.

**Derived from:** Nb2-N5. **Connections:** N2/N3/N8 and A4; receptor-context
logic is analogous to A12, without adding a duplicate IL1 question.

**RQ.** Do ligand/input and receptor context generate distinct outputs after
canonical engagement, exposure and starting state are made comparable?

**Proposed hypothesis.** Receptor/co-receptor context changes the balance of
canonical and other outputs, so some differentiation-associated differences
persist beyond what a common amplitude/time response can explain.

**Observed premise.** Both Fzd agonists have lower Wnt-clean but higher
source-YAP and AT1-associated scores than CHIR across omission checks. Fzd5/Fzd6
Wnt-clean point estimates are very similar, but equivalence is untested. The
source includes only one recombinant Wnt ligand and synthetic receptor agonists;
CHIR is an intracellular inhibitor with broader consequences.
[Executed N5](../RESULTS.md#n5-compare-response-profiles-before-attributing-ligand-routing).

**Test specification.** Unit: independent preparation; compare different inputs
within the same starting state and the same input across defined receptor
contexts. Require comparable measured engagement and time-resolved output,
with an explicit common-response model and an input/context-interaction rival.
Use within-study effects before any cross-study synthesis. Later fate or a
direct noncanonical functional endpoint must be specified separately. Conditioning
on a post-treatment Wnt score is not a causal mediation or dose-matching solution.

**Rival and falsifier.** If a common engagement/time response explains the
differences within useful precision, a distinct-routing interpretation weakens.
PCP, calcium, polarity and motility cannot be inferred from this RNA analysis.

**Current decision:** prioritize with the epithelial timing/state questions;
current profile differences motivate a mechanism test but do not identify one.
The endogenous-ligand issue is explicitly separated in N8.
