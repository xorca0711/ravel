# Nb2-N3 candidate: does starting state determine response beyond receptor abundance?

Paper-local interpretation draft. Not registered under `RQ_Specified`; its scope
may be merged, reframed or dropped after synthesis of the branch results.

**Derived from:** Nb2-N3. **Connections:** A1/A4/A8.

**RQ.** Does epithelial regulatory state modify the effect of matched Fzd
engagement on maintenance, transition and mature contribution?

**Proposed hypothesis.** Receptor availability is permissive, while co-receptor,
regulatory and niche context changes the downstream response: equal engagement
will not have the same fate effect in AT2, transitional and AT1-like states.

**Observed premise.** Day42 AT1−AT2 has more Fzd5 RNA but less Wnt-clean target RNA
in all four eligible matched samples. This contradicts a simple receptor-RNA
ordering of canonical output, not receptor function itself. Transitional labels
are too sparse: zero eligible units at day42 and only one at day11 at floor50.
[Executed N3](../RESULTS.md#n3-receptor-rna-and-canonical-target-rna-do-not-order-epithelial-states-alike).

**Test specification.** Unit: independent donor/animal/preparation with **baseline**
state determined before intervention. Primary estimand: treatment-by-starting-state
interaction for a linked later outcome, with receptor engagement measured.
Analyze changes within state separately from changes in state abundance and
survival. Use adequate replication for each intended state and a prespecified
state crosswalk. Regulatory measurements can test whether A1 adds information
beyond receptor expression; they do not by themselves establish fate.

**Rival and falsifier.** Sparse targets, RNA/protein discordance, unequal delivery
or selection can explain apparent state differences. The hypothesis weakens if
state differences disappear under comparable measured engagement and survival,
with sufficient precision for a defined useful interaction.

**Current decision:** retain the state-context question; do not invent a
transitional-state interaction or infer drug response from atlas projection.
Post-treatment state and pseudotime are not substitutes for baseline assignment.
