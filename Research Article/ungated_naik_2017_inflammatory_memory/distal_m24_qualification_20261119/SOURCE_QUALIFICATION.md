A full S2 interval `[a,b)` is distal only when it shares zero bases with every promoter. Ends that touch without sharing a base pass. Eligible TSSs formed 51,104 merged promoter intervals. Three equivalent checks agreed for every S2 row: promoter union overlap, TSSs in the expanded interval and nearest distance from any included peak base. There is overlap in acute induction and pooled abundance, with substantial imbalance. As a design diagnostic, we partitioned each covariate by quartiles pooled over the 1,575 eligible regions. Both classes occupy all 16 D6 log2 fold change × baseMean cells. Taking the smaller class count in each cell permits at most **329 one-to-one pairs** within those coarse cells. Adding width yields 54 shared cells out of 64 occupied, with 756 members of each class in shared cells and at most **328 coarse pairs**. Cut points, ties, all cell counts and class ranges are saved. These are upper bounds for these bins. They do not show fine-scale balance. No pairs were selected and no region was removed from the frozen primary cohort. [Support diagnostics](../../../analysis/research/runs/naik2017_distal_m24_metadata_v1/region_qualification.json)

S3 supplies the authors’ D6 log2 fold change, SE, Wald statistic and adjusted P. Its baseMean is the mean normalized count across the fitted object. The notebook restricts that object to six groups (D6/D30/M12 × naïve/history, four pools each), then calls the D6 contrast with `sub=FALSE`. Thus baseMean includes post-exposure and later samples. It is unsuitable as a D6 naïve abundance measure or strictly pre-recovery adjustment. The S3 summaries cannot recover group-specific D6 normalized counts, variance across control pools or overlap at a true D6 control baseline. A matched secondary description would have to state its smaller target and covariates. Matching on D6 induction alone tests sensitivity to acute strength. A genuine baseline-matched analysis needs per-library D6 counts over the same fixed intervals or a separately qualified reconstruction. ## What a future reader must distinguish

All four files have a matching BigWig lead/trailer signature, version 4, compressed primary data, eight zoom levels and identical 66-contig dictionaries. All 20 eligible chromosomes match UCSC mm10 by exact name and length. ChrY and chrM also match directly. Each of the other 44 unused scaffolds has one UCSC name with the same accession stem and length. A **header anomaly** affects all four: the raw binary total-summary count `basesCovered` is 3,817,419,287 to 3,900,932,695, greater than the 2,730,871,774 bases in the dictionary. The pybbi reader returns the identical header field. Its cause is unresolved. Do not use that field or a zoom summary as the actual covered length, interval denominator, or reason to fill gaps. [Header and probe evidence](../../../analysis/research/runs/naik2017_distal_m24_metadata_v1/track_structure.json)

We checked the same fixed twelve 10 kb probes in each library, disjoint from every S2 row. At each probe we reconciled clipped, nonoverlapping stored interval records with an exact unbinned base fetch using an explicit missing sentinel. All 480,000 queried library-bases had records. Each library contained explicit zero and nonzero bases. In the pinned independent reader fixture, one documented absent base returned NaN and three stored bases returned finite values. The rtracklayer RleList writer passes run ranges and values to its C writer, consistent with the explicit zeros observed here. These checks do not establish completeness at the study loci. [Structural qualification code](qualify_track_structure.py) · [Bioconductor RleList writer](https://github.com/bioc/rtracklayer/blob/RELEASE_3_21/R/bigWig.R) · [Reader provenance](../S3_RUNTIME_V1.md)

For review, use exact stored intervals or unbinned base arrays and verify each full width against the record mask. A measured zero contributes zero to the numerator and one base to the denominator. An absent base, nonfinite value, conflicting/overlapping record or out-of-bounds base should be reported distinctly and held for review before any affected class comparison. The reader’s default zero fill, a covered-bases-only average, sampling a few positions, or interpolated zoom bins could each change the estimand. No primary-interval query, coverage test or condition comparison was run here.

**Decision for the coordinator.** Advance the full 791/784 comparison to contract design if a late *unadjusted, exposed, pool-level* association is informative. Keep class summaries within each library and display all four pools. Any sensitivity to acute induction or width must preserve the interpretation of the complete primary cohort. The current inputs cannot establish independence from D6 control accessibility, a cell-intrinsic mechanism, or a precise population effect. The header anomaly makes exact per-region record accounting important at execution. It prevented no source joins or off-region structural checks.
