## Frozen baseline and support rules

1. Recheck the four immutable files and their dictionaries. On each interval use clipped primary records, a separate occupancy mask and an independent unbinned fetch with missing and out-of-bounds sentinels. On an in-bounds, declared chromosome, an uncovered position in this specific positive-depth export contributes zero **mapped-read depth** only when the native record mask and unbinned fetch agree on omission. Count implicit and explicitly stored zero bases separately. Sum over the entire interval width. An entirely unrecorded valid window has zero deposited depth. Ambiguous encoding, material evidence of extra masking, invalid coordinates or records, overlapping records, negative/nonfinite stored values, read errors and disagreement require a hold. Save all obtainable library diagnostics. This encoding applies only to the four named archive files.
2. Within each D6 library rank the 1,575 full-width means across both classes together, using centered percentile midranks `(average one-based rank − 0.5)/1,575`. Equal finite means, including zeros, share their exact average rank. Retain each library's raw mean, rank, zero/tie counts, largest tie, signal quantiles, and the six pairwise Spearman correlations and mean absolute rank differences. Average all four ranks equally. Sum the integer rank numerators before dividing, so equal consensus values cannot diverge through summation order. A constant library or consensus holds the endpoint. Disagreement across nonconstant libraries remains visible.
3. Reuse the original 16 induction-by-width cells and weights. Add one pooled consensus-rank quartile axis with type-7 cuts and ties assigned to the higher bin. Report all 64 cells, both class counts and the smaller count in each. Give each class the same cell mass proportional to that smaller count, distributed equally across its members. A cell missing a class has zero mass. Preserve all 1,575 rows. Hold the outcome if fewer than two baseline bins carry shared mass. Report the retained region counts, original mass retained, regional Kish effective sizes, largest weight, change in the distribution of weights, and original strata still represented. Compare class mean differences for induction, width, each control rank and consensus under unweighted, original, restricted and new weights. Use one pooled full-cohort within-class SD per covariate; a zero SD leaves the standardized difference undefined. Thin support or residual imbalance limits interpretation even when arithmetic is feasible.
4. Reuse the 6,300 saved M24 full-width fragment-CPM values after the baseline checks. For each class compute post-IMQ minus naïve using the two pool summaries per history, then subtract the Resolved change from the Memory change. Retain the four pools and four cross-pool comparisons for each weighting. First reproduce the frozen D6/width result. On the newly supported regions renormalize the original weights within each class to isolate the contribution of support restriction. Apply the new three-way weights on that same support to isolate redistribution. These two signed differences sum to the total change from the old target. Report attenuation, persistence, reversal or limited support as observed. No post-result alternative binning, cohort, track choice or equivalence threshold is specified. ## Exposure and interpretation

Cowley Fig. 1 showed the late trajectories. Class membership, D6 covariates and the M12 contribution to ascertainment are known. Step 4 at `cb55c05` exposed all M24 interval values and gap changes of +0.116973 (full mean), +0.073155 (median) and +0.121493 fragment CPM (D6/width-weighted mean). This sensitivity asks whether the contrast persists among regions comparable on the four observed D6 control rankings. It can change because the supported regions or their weights change. Control ranks measure relative deposited signal under a common archive processing method. The D6 arms belong to the original experiments and contributed to discovery. They do not supply paired baselines for M24 mice. Pooling, sorted-cell composition, residual within-bin differences and unknown animal membership limit any maintenance or repair interpretation.
