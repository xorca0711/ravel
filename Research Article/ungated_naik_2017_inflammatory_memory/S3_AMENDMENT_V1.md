# S3 prospective amendment: relative ordering near annotated gene boundaries

18 November 2026. Owner `Nk17-P01`. The coordinator explicitly reviewed and
approved this narrower adaptation after the completed [S3Q qualification](S3Q_RESULTS_V1.md),
preserved at `6f4fdf0`. This authorizes implementation and governed execution;
it does not create human scientific acceptance or change a claim grade.

The [historical plan](ANALYSIS_PLAN.md#s3--atac-persistence-at-a-defensible-resolution)
asks about retained accessibility under qualified region definitions and signal
semantics. Original retained-region coordinates and deposited normalization remain
unresolved. S3Q qualified source joins and core chromosome lengths but cannot
identify the signal transform. Neither the paper's Z-score description nor the
later Cowley/Larsen domain set resolves that original estimand.

This amendment introduces a different, finite-track endpoint: history-associated
changes in each library's relative ordering of exact deposited signal means over
an annotation-fixed collection of protein-coding gene 5′-boundary windows. It
can describe redistribution within that collection and its D6/D30/window-width
sensitivity. It cannot recover absolute accessibility, global opening, distal
memory domains or the paper's retained-region counts. Positive rank changes can
arise because other windows move downward; every library's average rank is fixed.

The [new method](S3_METHOD_V1.md) makes the universe, representation, ties,
missingness, exposed examples, independent verification and resource limits
prospective. It assumes the deposited ordering is interpretable within these
source libraries, while explicitly retaining unknown nonlinear processing,
clipping/smoothing, composition, pooled membership and assay pairing. Ranking
window means removes positive affine scale changes, not every possible unknown
preprocessing difference. The original magnitude-comparability boundary remains
in force for its own endpoint; this amendment is not evidence that it was met.

All original source files, S3Q outputs, S4/S4B results and the historical plan are
preserved. The new biological contract is an initial contract for this adapted
endpoint; no earlier biological S3 contract exists to populate `amendment_of`.
Its amendment reason and evidence references bind this decision explicitly.
After execution, return the actual evidence for coordinator review before S5/S6.
