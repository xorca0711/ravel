The [research roadmap](../../docs/RESEARCH_ROADMAP.md) places this contribution
primarily under source/receiver identity and coverage (P4) and measurement
definition (P0). It cannot supply P0's missing repair endpoint or P3's linked
regulatory-to-fate design. A normal reference may improve A1/A8 interpretation;
fibroblast context may inform A13/A22; Wnt-state ambiguity informs A4. These
are conditional connections, not additional independent support for those RQs.

The order is source/design intake -> versioned metadata -> source reconstruction
-> eligible descriptions -> sensitivities -> external eligibility -> separately
specified question. Expression integration is not the first step. Failed gates
are retained as outputs. Existing claims, analyses and global IDs are preserved.
