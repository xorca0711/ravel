# A12-adjacent ERBB reference: source decision and prospective specification v1

3 November 2026, Asia/Seoul. **Descriptive reference screen; target outcomes unseen at freeze.** This is separate from A12's closed IL-1 pilot and its unchanged replication hold. Coordinator reviewed the narrower route before execution; that is execution review, not scientific acceptance.

## Question and decision

Does the single source-defined fresh HTII-280-sorted preparation GSM4522986 provide measurable ERBB4 and ERBB2 RNA context? The unit reported is one deposited library/preparation; donor identity and independence remain unresolved. The endpoint is recovered RNA molecules, their full-feature denominator, barcode detection and co-detection. This can establish a measured RNA reference for this preparation, but cannot select between epithelial states or certify a functional experimental model.

Published Lin Fig. 7/S18 receptor perturbations distinguish origin/context; the repository has not recovered those replicate values. The original reference deposits offer counts, but recovered metadata cannot identify cell states in the mixed libraries. The remaining useful extension is a source-defined preparation description. Positive detection supplies an observational RNA reference; sparse/absent detection limits that reference without demonstrating absent protein/function. Ambient RNA, dropout, sorting heterogeneity and recovery/QC selection are consequential alternatives.

## Fixed numerical specification

- Analyze **only GSM4522986** original GEO counts. Resolve exactly ERBB4/ENSG00000178568 and ERBB2/ENSG00000141736. No extra panel or gene replacement. The feature metadata (not counts) was inspected before freeze.
- Two nested subsets: every deposited barcode, and author-method-informed **operational QC**: positive full RNA depth, 200 through 6000 detected features inclusive, and mitochondrial UMIs at most 10% of full-feature UMIs. Original wording excludes less than 200 genes, more than 10% mitochondrial reads and more than 6000 `unique gene counts`; this reconstruction interprets the last as detected features and uses UMI weighting. Original code is unavailable, so this is not exact author-QC reproduction. Mitochondrial features are the 13 source symbols beginning `MT-`; emit their identifiers.
- For each gene/subset report total UMIs, full-feature UMI denominator, 1,000,000 times their ratio, detection numerator and all-subset-barcode denominator. Co-detection requires at least one UMI of each target in the same barcode; it is not protein co-expression or receptor assembly. Retain zero-depth barcodes in deposited detection denominators; undefined normalization is NA. No per-cell inferential replication.
- Retain all QC exclusions and overlapping failure counts, unknown states/donors and every source-library status. The nine-library epithelial-state comparison remains **unestimated**, not a zero result. No cross-time donor pairing, re-clustering or marker-defined state substitution.
- No p-values, confidence intervals, expression threshold optimization, powered/equivalence claims or population effect. No inference of Lin perturbation response, IL-1 specificity, receptor activity, fate or mature alveolar function.
- Independent native R Matrix arithmetic must match every barcode, RNA/mitochondrial UMI total, detected-feature count, both target counts and QC membership; recompute all summaries from those independently loaded values. Fail for hash, dimension, duplicate/ambiguous ID, invalid coordinate/count, parity or runtime failure. Preserve unfavorable outcomes; any correction needs a new version.
