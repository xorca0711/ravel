# Research question homes

All **37 canonical questions (A0–A36)** have a dedicated home here. Folder presence
does not imply completed analysis, scientific acceptance or experimental readiness.
The [canonical register](../RESEARCH_QUESTIONS.md) owns identity; the
[registry](../analysis/research/registry.json) binds each home, context and figure.

[3 November evidence-trajectory review](../docs/audits/2026-11-03-rq-evidence-trajectory/README.md)
compares every question's first registered wording with its corrected results,
distinguishing empirical narrowing, useful negative diagnostics and untested
comparisons. It is an agent assessment, not a retain/reject decision.
[The cut-or-fill plan](../docs/audits/2026-11-03-rq-evidence-trajectory/CUT_OR_FILL_PLAN.md)
now gives a per-question interpretation boundary, bounded follow-up and stop rule;
each question home links its own row. The [five-package technical ledger](../docs/audits/2026-11-03-rq-evidence-trajectory/TECHNICAL_STATUS.md)
now records completed A25 prediction, A17 synthetic qualification and the
A5/A12/A30 source/join passes with their remaining downstream holds.
[Additional metadata screening and folder review](../docs/audits/2026-11-03-article-rq-screening/README.md)
identifies concrete recovery routes without reopening spent analyses.

## Reading order

Each question README starts with **Organizing Biological Q → Literature context &
visual hypothesis**, followed by current evidence, analysis records and next steps.
Read a current result or amendment before an older plan. The central scientific
dossier retains the full argument; paper-owned work and frozen runs stay at their
source locations. Local `scripts/`, `tables/`, `reports/` and `figures/` directories
exist only where the corresponding work exists.

[Question illustrations](SCHEMATIC_GALLERY.md) · [Searchable HTML gallery](SCHEMATIC_GALLERY.html) ·
[Measured-result figure index](FIGURES.md) · [Scientific dossiers](../docs/research_dossiers/README.md).

`schematics/` contains qualitative illustrations and prompts; `figures/` contains
measured-result figures where available. Shared or historical packages below are
supporting workspaces, not additional A-series identities.

## Browse by scientific contribution

| What the reader can inspect | Examples and interpretation boundary |
|---|---|
| A result narrows a component or context | A5's mixed member contributions, A12's epithelial/fibroblast prediction contrast and A31's conditional partner context. None establishes protein activity or function. |
| A proposed generalization does not hold | A0's frozen cross-tissue transfer, A21's inconsistent cycling rationale and A22's failed general identity-predictor transport. The negative comparisons restrict those explanations, not every related biological possibility. |
| A model or measurement limit becomes explicit | A17's observation ambiguity, A25's mixed gain over flexible age and A11's feature-capacity control. Diagnostics can determine what a future comparison must resolve. |
| Separating contributions changes interpretation | A28's RNA arms, A30's observed-state/activation comparison and A27's receptor-eligibility sensitivity. These distinguish measured patterns without assigning unobserved functions. |
| A focused question remains open | A1's regulatory feature and A32's linked metabolic/matrix/epithelial outcomes. Existing context can motivate a comparison without pretending it has been performed. |

These examples are reading routes, not scientific acceptance grades. The
[current restructuring review](../docs/research_reviews/2026-11-04-portfolio-reasoning-restructure/README.md)
records staged owner-page review. An older plan or a missing functional endpoint
does not automatically create a new active analysis task.
