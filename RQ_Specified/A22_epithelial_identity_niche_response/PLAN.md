# A22: proposed discriminating test

Status: a future biological test plan, derived after Nb3 inspection. This file
does not authorize claiming that the proposed experiments or validations ran.

| Element | Specification to carry into an eligible design |
|---|---|
| Primary question | Does an epithelial identity perturbation change fibroblast chemokine output after epithelial and fibroblast amounts/states are measured separately? |
| Biological unit | Identified independent epithelial preparation and fibroblast donor/preparation; repeated wells nested within these units |
| Primary response | A prospectively fixed secreted chemokine endpoint in the fibroblast-recipient system, with viable fibroblast amount measured; CCL2 is a source-supported candidate, not a validated mediator |
| Secondary functional response | Recipient-cell migration or recruitment measured separately from viability and proliferation; identify the responding cell class in advance |
| Required exposure evidence | NKX2-1 protein/identity state, perturbation validity and epithelial amount; RNA knockdown alone is insufficient |
| Comparators | Identity alteration with measured growth/composition, growth alteration without the same identity change, and matched unperturbed controls |
| Discrimination | Recipient output should track independently established identity change and its restoration when competing amount/state explanations are bounded |
| Analysis | Preparation/donor-level contrasts or a prespecified hierarchical model; retain technical-well nesting, effect intervals and relevant covariates without treating post-treatment conditioning as causality |
| Freeze before testing | Primary endpoint, biologically meaningful effect margin, variance/power basis, valid perturbation criterion, exclusions, covariates and multiplicity family |

**Support would require** a consistent change in the nominated secreted output
and corresponding recipient function across independent units, with measured
state/amount alternatives addressed. Restoration or recipient-side evidence
would strengthen directionality, but no one RNA score establishes mediation.

**The hypothesis would be weakened** if secretion/function remains unchanged
with sufficiently precise bounds despite verified identity loss, or if the
observed response is accounted for by independently measured cell abundance/
state composition. A failed perturbation or uninformative interval is
inconclusive rather than evidence against the biological proposition.

Stage 0 is complete: the Nb3 local sensitivity and transcriptional-context
analyses. Stage 1 is eligibility of an independently replicated, appropriately
measured dataset/design. Source-reused GSE215824, unresolved spatial bins and
the same 771 bulk wells do not become an independent validation cohort. The
numeric S5 conflict requires correction/code for an exact source-reproduction
claim; it does not justify altering Nb3's verified count-derived estimates.

No confirmatory power threshold is invented from this screen's technical
variance. These decisions require an eligible biological design before fitting.
