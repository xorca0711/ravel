# A32 development plan

2 November 2026. Proposed exposed functional extension of Yd1-P02. Read the
[current dossier](../../docs/research_dossiers/A32.md), [literature context](LITERATURE_CONTEXT.md)
and preserved [T2 disposition](../Yadav_followups_20261031/T2_DISPOSITION.md).
This is a design/eligibility plan, not an executable analysis contract.

| Step | Purpose and endpoint | Status / evidence needed |
|---|---|---|
| P0 | Review distinct scope, published premise and existing RQ overlap | Completed registration assessment; no novelty or scientific-acceptance certification |
| P1 | Qualify source, fibroblast and epithelial model/data identities, source restriction, allocation and biological-unit crossing/nesting | Held: no confirmed host model or qualifying linked dataset in the reviewed record |
| P2 | Validate absolute lineage-derived mature output and separately measured new/deposited collagen in the same design | Held: mature-function assay, timing and per-unit endpoint linkage not qualified; Atg5 organoid/marker evidence is a different perturbation |
| P3 | Define comparison, target engagement, viable source/recipient amount and inflammatory context; retain early survival/expansion measurements | Held on actual model and measurement qualification; choose attribution controls for the claim sought rather than imposing a generic experiment template |
| P4 | Freeze a numerical contract with source hashes, exposure, contrasts, unit model, endpoint priority, meaningful margins and precision | Held: qualified inputs, variance and margins absent; no invented sample size or equivalence threshold |
| P5 | Estimate separate epithelial and collagen effects; inspect dependence, selection and validity threats | Unexecuted; conditional on P1–P4. Do not pool unrelated papers into a joint correlation |
| P6 | Review all effects, negative results and uncertainty; add stronger mediation claims only with their own identification evidence | Unexecuted; a favorable pair of endpoint effects alone does not identify the fibroblast route |

Preserve all earlier numerical results and failed/held source qualifications.
Registration does not authorize a new mechanism, intervention optimization or
pathogen experiment. Reopen empirical work only when the specified source,
model, linkage and endpoint evidence changes.
