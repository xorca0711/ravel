# A23: proposed homeostasis-to-state test

Status: future discriminating design, derived after the completed Nb3
descriptive batch. No prospective experiment or independent validation is
reported as executed.

| Element | Required specification |
|---|---|
| Primary question | Does independently verified disruption of SLC34A2-associated phosphate homeostasis change the probability/intensity of transition-associated epithelial state before broad loss of alveolar identity? |
| Biological unit | Independent animals, donors or epithelial preparations, with technical wells/cells nested inside them |
| Exposure | Valid perturbation plus transporter/protein or transport-function evidence; independently measured relevant phosphate condition |
| State response | A fixed transition definition not containing Slc34a2, analysed within independently defined epithelial states and separately as population composition |
| Time response | More than one time point with known sampling/lineage relationships; destructive snapshots must not be described as the same cells changing fate |
| Main comparison | Perturbation versus matched controls, with a separately interpreted restoration/complementary homeostasis contrast and measured viability/proliferation |
| Functional extension | Mature AT1 contribution and recovery after normalization, measured separately from KRT8 expression and organoid size |
| Major rivals | Pre-existing state mixture, generic stress, off-target effects, cell-cycle changes and secondary extracellular mineral/inflammatory injury |
| Analysis | Biological-unit contrasts; within-state and composition effects reported separately; prespecified temporal and restoration comparisons |
| Prospective freeze | Biological effect margin, power basis, state definitions, valid perturbation and transport criteria, time windows, exclusions and multiplicity |

**Support would require** an independently reproduced transition-associated
response with verified transport/homeostasis change, appropriate temporal
ordering and a discriminating restoration result. A weaker identity change than
NKX21 is descriptive context, not a substitute for these measurements.

**The homeostasis hypothesis would be weakened** by a precise absence of state
response despite a verified relevant defect, or by an effect explained by
independently established cell-mixture changes without a within-state response.
Failure to restore the state after verified normalization would challenge the
reversible version, while leaving alternative persistent or indirect mechanisms
open. None of these conclusions follows from an underpowered or invalid assay.

The source-evidence stage is complete under Nb3. A23's [pipeline](PIPELINE.md)
now separates verified P0 intake, P1 source eligibility, P2 external PAM
case-context inspection, P3 transport/secondary-injury linkage, P4 temporal
ordering, P5 restoration and mature recovery, and P6 synthesis. The existing
paired-depth result concerns AT2 identity in seven wells; no transition-panel
depth fit was performed. Only intake and external metadata review have run as
new A23 work. Suitable replicated time/transport-linked data remain unestablished. GSE307112 is the discovery screen, not its own validation set;
GSE215824 is source-reused NKX2-1 context, not an SLC34A2 validation cohort.
The current data do not justify an optimal intervention, clinical inference or
a claim of normal versus fibrotic cell fate.
